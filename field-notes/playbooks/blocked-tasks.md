# Tasks that unblock themselves

A blocked task needs something that will unblock it. Otherwise it waits forever.

We once counted 27 blocked tasks. Five were marked blocked by hand, with nothing that could clear them.

## How it runs

1. List the blocked tasks.
2. For each one, name what clears it: another task finishing, a person's answer, or a date.
3. Turn "blocked on X" written in the text into a real link, a question or a date.
4. Before you set an order of work, keep only the tasks that can start.
