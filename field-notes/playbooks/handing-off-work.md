# Handing work to another agent

A "sent" from the messaging tool only means the message was typed.

A 6.5 KB prompt sent inline came back "OK, sent". The other agent never ran it.
Our send tool now says so when a message was typed but may not have gone through.

## How it runs

1. Write the work into a file or onto the task. Send a short message that points to it.
2. Quote the message so the shell doesn't eat the backticks in it.
3. Check that the other agent started. If you can't, put the work on the task board instead.
4. For scheduled messages, check that each one ran.
