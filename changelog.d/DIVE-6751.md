## Unreleased — fix(agent): --no-skills installs no default skills (DIVE-6751)

`5dive agent create --no-skills` used to opt out of the `--with-skills` extras only; every preseed path still seeded the defaults (5dive-cli, compile-knowledge). The flag now skips the default skills too, the seat is recorded as `noSkills: true`, and the nightly skill refresh leaves it alone. `pack import` keeps the defaults for imported agents.
