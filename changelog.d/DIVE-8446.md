## Unreleased — secret https: a self-hosted box gets its <name>.5dive.app when it first needs https (DIVE-8446)

A self-hosted server is no longer named when it links to 5dive.app. The first time
`5dive secret https` needs a front (the first `secret link`, or
`secret https enable --via=5dive-app|auto`), it asks 5dive.app to make the name, and
serves on it. 5dive.app gives out a limited number of free names a week; past that the
server gets none and uses the IP certificate, as before, and asks again only at its next
`secret https enable`. A server that already has a name asks nothing.
