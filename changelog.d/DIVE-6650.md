## Unreleased — fix(plugin): plugin upgrade keeps the newest 3 versions of a plugin (DIVE-6650)

`plugin upgrade` installed each new version beside the old ones and never deleted any. Since
self-update upgrades official box plugins every night, the store grew by one full copy per
release: one box held 22 browser versions, 373 MB, at 88% disk.

An upgrade now keeps the newest 3 version dirs of that plugin and deletes the rest. It never
deletes the enabled version, the version the box records (a disabled plugin keeps it), or any
version an agent's own plugin list still pins. If an agent's plugin list cannot be read, it
deletes nothing. `plugin rollback` still lands on the previous version. The same-version
nightly run prunes too, so existing boxes reclaim the space on their next night with no
migration. `FIVEDIVE_PLUGIN_KEEP_VERSIONS` changes the count.

`tests/plugin_version_prune_unit.sh` adds 14 arms; 5 are red on main.
