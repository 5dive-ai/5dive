## Unreleased — fix(codex): Codex agents sharing a ChatGPT sign-in stay signed in, and their app chat starts (DIVE-7724)

- **One ChatGPT sign-in, many Codex agents.** A ChatGPT refresh token works once. When one agent refreshed its copy, the account kept the spent one, so the next agent hired on it (and any other agent at its next refresh) came up signed out. Now the newest copy wins: every heartbeat tick, at sign-in and before an agent starts, the box hands it back to the account and out to every agent on that same ChatGPT account. A copy of a different account or an API-key login is never touched.
- **App chat on a Codex agent no longer crash-loops.** Importing a pack onto a Codex agent made `~/.claude` owned by root, and the app chat could not start. The import now makes it the agent's, the chat setup repairs it, the agent's start prints one clear line when it is still wrong, and `5dive doctor` names it (`--fix` repairs it).
