## Unreleased — fix(people): an Admin set in the app becomes an owner of the agent's Telegram bot, so the Connect sign-in buttons reach her too (DIVE-8378)

Owner-only Telegram notices (browser Connect sign-in buttons, usage-limit notices, group
auto-approve) go to the bot's `owners` only. People wrote a co-owner into `allowFrom` but never
into `owners`, so the only way to add a second owner was the terminal `/telegram:access owner add`.

- **`5dive people sync`** now adds the Telegram id of every Owner and Admin person allowed on an
  agent to that bot's `owners`, and removes only ids it added itself (tracked in
  `people-owners.json` beside `access.json`; the channel server rewrites `access.json` with known
  keys only, so a tracking key there would not survive a pairing). The first paired owner and any
  hand-added owner survive every sync. The record is stamped `ownersSeed: 2`; an unstamped
  old-seed record is first trimmed to its first paired user, as the plugin would, so the stamp
  never freezes clients in. Pairing and `allowFrom` are still not an owner signal (DIVE-5867).
