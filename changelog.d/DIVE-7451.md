## Unreleased — feat(voice): a self-hosted server offers speech-to-text on first use (DIVE-7451)

A self-hosted box had no speech-to-text of its own: voice came only with
`plugin add voice` + `voice setup`, which nobody ran, so its voice notes were
heard on 5dive's server and an encrypted chat had no voice mode at all.

- Nothing is installed unasked: not at `5dive init`, not by self-update.
- On first use (a voice note in any channel, or the owner asking for voice) the
  agent asks once: «Install speech-to-text on your server? (about 2 min, keeps
  voice private)». Yes installs it and that note is heard on the box after. No is
  remembered and never asked again unless the owner asks for voice. The agent
  learns this from a short block synced into `projects/CLAUDE.md` on self-hosted
  boxes only.
- `sudo 5dive plugin auto-voice --status|--on|--wait|--off` is what the agent
  runs (and the owner can too). Who chose it is recorded
  (`/var/lib/5dive/voice-auto`); `plugin remove voice` records an owner's off.
  Boxes 5dive runs are untouched.
- Cost, measured on a fresh Ubuntu 24.04 box: 1091 MB of disk, 390 MB peak
  memory, about a minute to install.
