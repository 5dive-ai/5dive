## Unreleased — feat(voice): a self-hosted server hears voice notes on itself, by default where it fits (DIVE-7451)

A self-hosted box used to have no speech-to-text of its own: voice came only
with `plugin add voice` + `voice setup`, which nobody ran, so its voice notes
were heard on 5dive's server and an encrypted chat had no voice mode at all.

- `5dive init` on a box with about 2 GB of memory or more (and ~3 GB free disk)
  turns voice on by itself and says so in one line. The speech model (whisper
  `base`, the plugin's own default) installs in the background.
- Below 2 GB, init asks once: "Turn on voice? (puts a speech model on this
  server)". Not now is the default there.
- `5dive self-update` (and the nightly) turns it on once for a box set up
  before this, under the same bar.
- Who chose it is recorded (`/var/lib/5dive/voice-auto`). An owner who removed
  voice or said no is never switched back on. Boxes 5dive runs are untouched.
- `sudo 5dive plugin auto-voice --on|--off|--status` is the owner's switch.
