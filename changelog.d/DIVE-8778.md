## Unreleased — fix(goal): the planner's plan reaches the goal again (DIVE-8778)

Since 0.137 every `goal add` failed with "planner returned an empty or invalid plan": the planner
agent was woken with the usual "close with one or two sentences" line, so it saved the JSON plan to
a file and closed its task with a summary. A task that asks for a JSON result (the goal planner, a
loop grader) is now told to close with `task done --result-file=<the JSON file>`, the planner prompt
says the same, and a plan wrapped in a code fence or a sentence is still taken. Other tasks' wake
line is unchanged.
