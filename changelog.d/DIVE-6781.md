## Unreleased — fix(install): the install and `5dive init` end with how to reach your agents from your phone (DIVE-6781)

The open-source install never said the 5dive app exists. A self-hosted user can link their
own server to 5dive.app for free through the connector, and nothing in the install, the
first-run wizard or the README told them.

`install.sh` and `5dive init` now end with one short block, in the same three steps as the
own-server onboarding: paste the connector's install and `connect` lines on your server, your
server shows a code, type the code at 5dive.app. It stays quiet on a server 5dive built
(already linked to its owner's account) and on one whose connector is already linked, and
`FIVEDIVE_APP_HINT=0` turns it off. Both READMEs carry the same two commands near the top,
with a screenshot of the app.

`tests/app_hint_unit.sh` grades the block's words, both silences, the off switch, the wiring
into the installer and the wizard, and that both READMEs carry the same commands above their
first section.
