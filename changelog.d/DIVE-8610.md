## Unreleased — fix(account): moving an office AI to a new model moves its agents too (DIVE-8610)

`5dive account add <name> --provider=custom ... --replace` with a new `--model` now moves every Claude agent on that account to the new model. Before, each agent kept asking the AI server for the old model, the server refused it, and staff in the office chat waited on "Working…" with no answer. An agent left on a Claude model id moves too. An agent set to a bare `opus`/`sonnet`/`haiku`, or deliberately to another model, is left as it is; a parked agent is moved but not started.
