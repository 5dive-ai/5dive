## Unreleased — fix(install): boxes installed before the team wiki existed get one on their next update (DIVE-9481)

The shared team wiki (`/var/lib/5dive/wiki`) was created only by a fresh install. The nightly update runs the installer's upgrade path, which never reached that step, so every box installed before 2026-09-10 had no wiki: `5dive memory add --store=wiki` refused, new agents inherited no team knowledge, and the MCP wiki search always said "This team has no shared wiki yet."

Both paths now create it, the same way (2775 root:claude, an index seeded only when missing, existing pages untouched). A box that cannot create it warns and the update goes on.
