## Unreleased — feat(team): Team freedom is set per agent (DIVE-8872)

`sudo 5dive team freedom ask|balanced|yolo --agent=<name>` sets one agent's level: its Proactive,
its email gates and, for a Claude agent, its autonomy. Without `--agent` it still sets every agent.
`5dive team freedom --agent=<name> --json` answers `{agent, level, label, set_level, set_at, set_by,
differs, browser, levels}`; without `--agent` the answer lists every agent under `agents`. The
browser's asks are one setting for the whole box, so the browser follows the most careful level
any agent is on, and its asks stop only once every agent is on YOLO. New agents start on Balanced
once Team freedom has been used on the box; before that, nothing changes.
