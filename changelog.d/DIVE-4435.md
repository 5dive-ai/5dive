## Unreleased — fix(tests): un-red main — grade the restart seam's FACTS, and stop stamping a handshake off a frozen clock (DIVE-4435)

`origin/main` was red on two harnesses at once, and they turned out to be two unrelated bugs
wearing one label. Every PR inherited both, so `mergeable_state` read `blocked` repo-wide and
armed auto-merges did not fire.

- **`tests/codex_channel_e2e_unit.sh` stage C3 asserted another repo's exact sentence.**
  `.github` clones `5dive-plugins` **unpinned at run time**, so the harness grades this tree
  against whatever that repo's default branch is at that instant — and DIVE-3965 made the
  restart notice cause-aware, prepending a recovery-context element to the next turn's input.
  An exact-string arm here therefore reds *our* main on a merge to a repo we do not own, with
  zero changes on this side. Proven by a same-sha split: head `e2d95b3e` has one green and one
  red complete run, 14 minutes apart, identical tree.
  The arms now grade the **facts** instead of the sentence — the notice names an outage (both
  cause branches), the notice is not the lost message echoed back, and the queued text survives
  **verbatim as its own input element, exactly once** (index-free, so a prepended element is
  allowed while a dropped or duplicated message still reds). Green against `plugins@69f4557`
  (the new behaviour) **and** `plugins@e0cb2a3` (the old one), so the coupling is gone rather
  than re-aimed at today's string.
- **`tests/codex_channel_health_unit.sh` 5.3/5.7 were never a cross-repo failure.** The harness
  freezes `NOW=2026-09-13T12:00:00Z` and stamps its fixture at `NOW-5s`, but those two arms
  reach the classifier through `agent_channel_handshake`, which takes no `now` and reads the
  real clock. With a 60s freshness window the fixture was fresh for exactly 60 seconds of one
  calendar day and `stale` for all time after — a dated time bomb that would have re-red main
  every day. Those arms now stamp off the clock the unpinned path actually reads, plus a new
  arm 5.3b (an out-of-window record is **not** believed) so freshness is still graded rather
  than assumed.

removes one seam from the blast radius; it does not disarm the generator.
