## Unreleased — fix(task): a gate filed by root, cron or council no longer strands the row (DIVE-8875)

When a gate was filed without an agent behind it (the heartbeat's work-budget stop, any root or
cron caller, or `--from=council`), the row moved to that non-agent name, which nothing ever picks
up, so answering "keep going" resumed nothing. The row now stays with the agent working it, and the
answer wakes that agent. `task orphans` no longer suggests a "did you mean" seat for `cli`.
