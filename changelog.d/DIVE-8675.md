## Unreleased — feat(agent switch): --keep-model keeps a Hermes or OpenClaw agent's own AI model (DIVE-8675)

`5dive agent switch <name> --to=claude --keep-model` moves a Hermes or OpenClaw agent onto Claude Code without moving it onto your Claude plan: an agent on DeepSeek, Kimi, Qwen, GLM or OpenRouter keeps its own key and the same model, through that provider's Claude-compatible address. It gets its own account named after it (for example `theo-deepseek`), so no other agent's account changes, and no Claude sign-in is needed. An agent on a provider Claude Code cannot reach (plain OpenAI, Google) is refused before anything changes, with the way out. Also fixed: a Hermes agent with no Telegram allowlist no longer stops halfway through a switch.
