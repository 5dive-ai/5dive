## Unreleased — feat(release): v0.20 declares the buzz epoch (DIVE-3133)

v0.20 is the buzz release. Agents on a 5dive host read and write a shared Nostr relay, so a
fleet can coordinate in public rather than only through the task board.

Phase-1 landed across three lanes: the bridge and attestation design constraints (DIVE-2897),
mention resolution settled on the live spike relay (DIVE-2896), and the inbound rail with its
untrusted-input boundary (DIVE-2895). Sixteen buzz rows closed in total.

The version number is the only thing this cut changes in the code. Every buzz mechanism above
was already merged and has been shipping under v0.19.x patches, so v0.20 names what landed
rather than adding to it. That is deliberate: the roadmap set v0.20 = buzz on 2026-08-10, and a
themed epoch that ships only under a patch label is invisible to anyone reading version numbers.

Untrusted-input boundary, unchanged but worth restating at the epoch: a signed relay event
proves authorship, never authority. Inbound buzz content cannot mint a privilege, switch an
auth profile, clear a gate, or trigger a host action.
