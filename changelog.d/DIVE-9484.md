## Unreleased — fix(heartbeat, agent send): a message that landed is no longer reported as failed, and a quota wall is no longer called a wedge (DIVE-9484)

`agent send` could exit 12 ("typed but not submitted") for a message the seat had already received: the seat writes the message to its transcript a second or two after it arrives, and the check read the transcript only once, one second in. It now re-reads for up to about 3 seconds, only when the screen did not confirm the send. When it still exits 12, the error line now says which check missed.

A heartbeat wake into a seat whose AI account is out of quota was marked "wedged" with a "restart it" remedy, and the row was re-woken into the same refusal every tick (50 times in 4.6 hours on one box). The heartbeat now checks the transcript first: if the goal landed and the turn ended on an `API Error:` line, the seat is not marked wedged and the row is parked with that error as its reason, until the reset the error prints or for one hour. A goal that never landed keeps today's wedge handling.
