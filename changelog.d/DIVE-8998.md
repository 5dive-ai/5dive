## Unreleased — fix: two self-hosted box gaps, secret https status and Google sign-in (DIVE-8998)

### Fixed

- **`5dive secret https status` no longer exits 1 with no message on a box that never set up https.**
  A missing `/etc/5dive/secret-drop.env` now reads as "no value", so status prints its
  "no https address yet" line (report 1321).
- **`5dive tool google start` and the Tailscale join work on a self-installed box.** The CLI now
  ships `5dive-ensure-cli`, the on-demand installer for gcloud and tailscale, as a
  `host-scripts.manifest` entry, so curl-install, the .deb and `5dive self-update` all put it in
  `/usr/local/bin`. Before, only managed provisioning wrote it (report 1322).
