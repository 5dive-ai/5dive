## Unreleased — fix(memory): search finds Russian and Chinese words (DIVE-8108)

`5dive memory search` dropped every letter outside a-z, so a query in Russian
or Chinese matched nothing and printed an empty result. It now reads words in
any script, splits Chinese, Japanese and Korean text into two-character pieces,
and, when a word finds nothing, retries with words that start with it ("стоянк"
finds "стоянка"). A query with no words at all now says so and exits with an
error instead of printing an empty result.
