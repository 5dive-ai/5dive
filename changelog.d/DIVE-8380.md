## Unreleased — fix(tool): an amoCRM long-lived token is accepted (DIVE-8380)

`5dive tool set` now takes a key or token of up to 4,096 characters, up from 1,024. An amoCRM
long-lived token is a signed JWT that runs past 1,024, so it was refused with "must be one line
of printable characters, no spaces or quotes" although it had neither. The no-space, no-quote
rule is unchanged.
