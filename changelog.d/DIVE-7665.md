## Unreleased — fix(offline): the update file and the USB installer are 40% smaller (DIVE-7665)

`5dive-offline-<version>.tar` carried the 102 MB bun engine uncompressed. The file is now gzipped
as a whole (same name, same six members, same signature), and source maps inside the plugins'
packages are left out. Measured on 0.117.0's contents: the update file goes from 145 MiB to
83 MiB, and `5dive-usb-<version>.run` from 175 MiB to 114 MiB.

A box on 0.117.0 installs the new file unchanged: GNU tar opens a gzipped archive with the same
commands, so the reader already shipped takes it (a test runs 0.117.0's own verifier on it). The
new reader still takes an old, plain file, and a file whose gzip bytes were changed is refused.
