## Unreleased — feat(agent switch): a Hermes or OpenClaw agent moves onto Claude Code in place (DIVE-8672)

`5dive agent switch <name> --to=claude` now works for a Hermes or OpenClaw agent, so it runs on your Claude plan instead of an API key, without rebuilding it. It keeps its name, Telegram bot, tasks and access. Its instructions (Hermes SOUL.md; OpenClaw AGENTS.md, SOUL.md, IDENTITY.md) go into CLAUDE.md, its memory becomes 5dive memory that `5dive memory search` finds, and the skills you added are copied over. The harness's own Telegram gateway is stopped first, so the bot is never polled twice. The switch refuses if the server has no Claude sign-in (`5dive agent auth start claude`), and the result lists what did not move: the harness's own scheduled jobs and its built-in skills. One way for now: switching back, and keeping a non-Claude model, are later changes.
