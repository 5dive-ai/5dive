## Unreleased — chore(devteam): two heartbeat sweeps and the dev-team scripts and docs leave the core (DIVE-9281)

No behaviour change on a box without the devteam plugin: both sweeps already skipped there.

- The gate-shipped flag sweep and the forge merge poll (about 280 lines of `src/cmd_heartbeat.sh`) moved to the devteam plugin 0.4.5. The tick keeps `_hb_gate_shipped_sweep` and `_hb_forge_merge_sweep` as short calls into the plugin; the poll keeps its off switch (`FIVEDIVE_FORGE_MERGE_POLL=off`) and its no-plugin answer. A plugin older than 0.4.5 logs that the poll did not run and how to upgrade.
- `scripts/grade-burn.sh`, `scripts/dispatch-bytes.sh`, `scripts/publish-zero-human.sh`, `docs/zero-human.md` and `docs/delegated-push.md` moved to the devteam plugin. README, guide and `5dive --help` link there.
- `.github/workflows/badge-staleness.yml` stays: it runs on GitHub and writes this repo's own `status` branch with this repo's token, so in another repo it would need a stored cross-repo key.
- The devteam CI pin moved to the plugin commit that carries the sweeps.
