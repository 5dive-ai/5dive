## Unreleased — fix(agent): a restarted Claude seat no longer opens the "make auto mode your default?" prompt

Seats created before this flag was seeded at create time could show Claude Code's "Make auto mode your default permission mode?" prompt after a restart (seen after switching a seat's AI account). The next Telegram message or task then went into the prompt: the message was lost and the seat switched itself to auto mode. Every Claude seat now gets the flag on each start, so existing seats are fixed on their next restart. Everything else in the seat's Claude Code config is kept.
