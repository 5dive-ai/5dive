## Unreleased — fix(claudemd): the box file's managed blocks fit their share of the combined cap again, and this repo now grades that share (DIVE-5904)

A 5dive-built box's `projects/CLAUDE.md` is two repos' text: the API writes its half (capped at 220
words), then this install syncs the task-lifecycle and hired-agents blocks under it, and the API caps
the sum at 600. The "Except a hire" clause took the blocks from 370 to 386 words, so the combined file
read 604 and the API's main went red on its next, unrelated push. The lifecycle block drops six words
with every rule kept ("with a verifier" for "on a row with a verifier", "note alternatives",
"unless run with `FIVEDIVE_KEEP_ALIVE=1`", a semicolon for "as"): blocks 380, combined 598.
`tests/projects_claudemd_lean_unit.sh` now caps the two blocks at 600 − 220 = 380, so a block that
outgrows its share reds this repo's PR instead of the API's main.
