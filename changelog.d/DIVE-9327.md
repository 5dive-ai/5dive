## Unreleased — chore(core): the phone-push helper moves to the hosted plugin (DIVE-9327)

`push-notify.sh`, which sends the owner a phone push when an agent fails, only talks to 5dive's own servers as the box, so it left the public core for `hosted@5dive-plugins` (0.2.0, `lib/push-notify.sh`, unchanged).

On a box 5dive built, every install and upgrade copies the plugin's file to `/usr/local/lib/5dive/push-notify.sh`, the same path the agents' sudoers grants name, so no grant changes. It copies only from a plugin directory nobody but root can write. A plugin older than 0.2.0 leaves the copy already on the box in place. A self-hosted box stops receiving the file; there it was always a no-op.
