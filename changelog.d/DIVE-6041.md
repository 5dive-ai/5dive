## Unreleased — fix(ci): the nightly full-sweep no longer cancels the push sweep on the same commit (DIVE-6041)

`full-sweep`'s concurrency group is now keyed on the event as well as the ref. Keyed
on the ref alone, the 03:17Z schedule run cancelled an in-progress push run on the
SAME sha; the cancelled check runs stayed on the commit and main's status rollup read
FAILURE although the surviving run passed (85c4c835 sat red ~16h on 2026-10-11).
Pushes still collapse into one sweep of the newest tip; the nightly now runs beside a
push sweep instead of through it.
