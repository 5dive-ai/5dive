## Unreleased — feat(agent): agent list flags a Team/Enterprise seat whose org has channels switched off (DIVE-5993)

On a Claude Team or Enterprise login, Claude Code keeps every channel (Telegram, dashboard chat)
off unless the org's managed settings say `channelsEnabled: true`, and drops inbound messages
silently. The org's own settings replace the box's `/etc/claude-code/managed-settings.json`
whenever they hold any key, so an org that set any policy without that line silences the agent.

`agent list --json` now reports `orgChannelsOff: true` on such a seat (plan read from the seat's
Claude credentials, policy from `~/.claude/remote-settings.json`, else the box file), and
`orgBlocksChannels` lists every channel plugin the seat runs, the entries the admin adds next to
`channelsEnabled: true`. Both are `null` for personal plans and once the admin turns channels on
and the agent restarts.
