## Unreleased — feat(task loop): self-improving loops: one small change per run, kept only if the next run scores higher, with undo (DIVE-8692)

`5dive task loop improve <loop> on` makes a scheduled loop improve itself: after each run it is graded 0-100, one small change to its instructions is tried, and the change is kept only if the next run scores higher, otherwise put back. `log --json` lists every change with its scores and cost, and `undo <id>` restores the text exactly as it was. A change can never widen what the loop may do: new spend, posting, recipients, tools or links are refused, and any sentence that sets a limit ("Do not send it.", "until approved") is read-only to the improver. `task ls --recurring --json` shows `self_improving` and the current `score`. Off by default, per loop.
