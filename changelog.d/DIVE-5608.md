## Unreleased — fix(self-update): Codex agents take their bridge update once they are idle (DIVE-5608)

A Codex agent that talks over Telegram or the dashboard runs a dispatcher instead of a terminal
session. The restart check could not see it: there is no Claude session to ask, and the terminal
only shows the dispatcher's log, never an input prompt. So it read such an agent as busy forever.
The nightly update installed new bridge versions on disk, but the running agent never restarted
onto them (one agent stayed on 0.5.30 with 0.5.32 installed, so its typing and formatting fixes
never ran). The check now reads the dispatcher's own status file. No active turn, an empty queue
and an empty inbox mean idle, and the owed restart fires. An active turn or a queued message still
defers it. A stale, missing or unknown-format status file gives no reading, and the old (deferring)
checks still decide.
