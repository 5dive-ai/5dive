## Unreleased — feat(secret): save a login once for agents to type into a site, through the one-time link (DIVE-6844)

An owner can keep a login or a detail on the box for agents to use, without it ever being shown
in chat. It is one more secret in the box's store: one line per name in
`/etc/5dive/connectors/saved.env` (600, root), which no agent seat can read.

- **`secret link --save=<name>`** mints the one-time link with no task. The owner pastes the
  value on the box's own page, and it goes from the phone to the box only. A new link for a name
  that is already saved replaces the value, and never shows the old one.
- **`secret saved ls`** lists the names, never a value. **`secret saved rm <name>`** forgets one.
- A name is lowercase letters, digits and dashes (`linkedin-password`). A saved value is one line:
  it is typed into one field of a page.
- An agent uses one by name in the browser (5dive-browser: `act` with `"saved":"<name>"`). The
  browser ties each value to the site it is first used on (`saved.hosts`); a new value or a remove
  frees it.
