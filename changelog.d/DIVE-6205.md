## Unreleased — fix(secret): the drop page answers once the value is saved; one live link per gate; a closed link says closed (DIVE-6205)

- **The secret drop page no longer says "Nothing was saved" after it saved.** On the drop path,
  `task answer` records the gate and hands the filer's wake off (a transient systemd unit, else a
  detached child), so a seat held mid-turn no longer pushes the page past its 60s timeout. If a
  timeout still happens, the page says the value may have been saved and to ask the agent first.
- **One live link per gate.** An agent's second `5dive secret link` for a gate whose link is still
  live exits 3 and names the expiry; `--again` mints a new one. The app's own card still re-mints.
- **A spent link says it is closed.** The `secrets.<box>` Caddy block serves the 410 "This request
  is closed" page when the drop page is not running, instead of Caddy's empty 502. An older block is
  upgraded once.
- `task need --type=secret` now says a one-time link went out, to whom and until when, and the
  heartbeat's GATED template gives the right `task need` flags for each gate type.
