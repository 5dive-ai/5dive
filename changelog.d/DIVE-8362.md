## Unreleased — fix(task): a lead that routes its owner's ask is taught --tell-me (DIVE-8362)

A lead that hands its owner's ask to a teammate is now told how to hear that it finished.
Before, the teammate finished, a reviewer accepted, and the owner got the file only when they
asked again.

- **Both runtimes are taught.** The team rules (Claude seats) and the Codex AGENTS.md baseline
  now say: file a routed ask with `--tell-me` (or `5dive task watch <id>` after), then send the
  owner the result itself, file attached, in one message, unasked. Grades stay on the board.
- **`task add` gives a hint.** A seat with its own Telegram chat that files a row to a different
  seat without `--tell-me` sees one `tip:` line (`tellMeTip` in `--json`). Nothing is armed by
  default: `--tell-me` is still opt-in.
- **`task show` shows the wake.** `tell_me_by` and `told_at` are always in `--json` (null when
  unset), and the text view says who is woken when the row closes, or how to arm it.
- The wake message asks for the result itself with the file, not "one plain line".

Existing seats get the new rules with this update's team-block and Codex-baseline sync.
