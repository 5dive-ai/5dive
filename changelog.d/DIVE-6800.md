## Unreleased — feat(install): install 5dive with apt from a signed package repo (DIVE-6800)

A second way to install, next to the curl one-liner: add our signed apt repo
once, then `sudo apt install 5dive && sudo 5dive-setup`. `sudo apt upgrade`
brings each new release; `sudo 5dive-setup` applies it to the box.

The package ships the release's installer bundle and runs that release's own
install.sh against it, so a package box and a curl box are laid out the same
way. Its install scripts fetch nothing and create no user; `5dive-setup` does
the box setup when you run it.

A new workflow builds the package from each release tag, signs the repo, tests
install, upgrade and the signature on a clean Ubuntu 24.04, and only then
publishes it.
