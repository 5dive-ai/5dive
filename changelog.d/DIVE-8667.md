## Unreleased — feat(agent switch): an agent's skills now move with it to the new harness (DIVE-8667)

`5dive agent switch` used to only list the skills that sat on the old side (Claude Code, Codex or Grok) as not carried. It now copies each of them into the new harness's skills folder, as the seat's own user, and keeps the old copy so a switch back reuses it. Skills 5dive installs in a separate version per harness (the Telegram notify-user skill and the other default skills) are not duplicated and stay listed as not carried. The result now names both lists: `copied` and `dropped`.
