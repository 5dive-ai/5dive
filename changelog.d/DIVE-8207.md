## Unreleased — fix(account): account list says which login was undone (DIVE-8207)

`5dive account list --json` now carries `undone: [<type>]` on an account whose login the owner took the default off with `account default --undo`. A caller that keeps its own fallback when the box marks no default (the partner cabinet picks the client's newest Claude) can then skip it, so Undo of «Your own AI» no longer hands new hires straight back to it.
