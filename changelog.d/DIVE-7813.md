## Unreleased — perf(agent): sharing an agent with its memory takes about a second, not a minute (DIVE-7813)

**`agent share --with-memory` is fast on a seat that has learned a lot.** Picking which facts
travel ran four small programs per fact, and the checksum list ran two more, so a seat with
1600 facts spent over a minute before its link existed. Both steps now read every fact in one
pass. The same facts travel and the same ones stay behind; only the wait changed (1600 facts:
74s down to about 1s). `agent export --with-memory` uses the same steps and speeds up with it.

`tests/agent_share_unit.sh` keeps its 1600-fact arm, now in seconds, and adds an arm that a
folder named like a fact is left out without stopping the rest, on both common versions of awk.
