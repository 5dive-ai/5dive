## Unreleased — fix(heartbeat): a '?' a seat only quoted is not a stuck question (DIVE-6515)

The stuck-question sweep read any `?` in a seat's final paragraph as an ask, including one inside a quoted UI label. On a box with no reflex model the base tier alone decides, so a seat that finished its row and mentioned Chrome's "Restore pages?" bubble reached its lead as "waiting for an answer" three times in two days. The base tier now reads the paragraph with quoted spans cut out first: `"…"`, `“…”`, inline code and fenced code. A real question beside a quoted label, or a `?` outside the quotes (`Ship it as "v2"?`), still forwards.
