## Unreleased — fix(plugin): a plugin with a setup step names that step for its packages, not npm (DIVE-6112)

`plugin add 5dive-ai/5dive-browser` printed the plugin's setup line and then a
second, stale one: "declares node packages that are NOT installed … Run this now:
sudo npm install --prefix …". On a fresh self-hosted box that line fails (there
is no npm yet), and `sudo 5dive browser setup` installs Node 22 and the pinned
package itself. A plugin whose manifest declares `fivedive.setup.command` now
owns its packages there: `add` prints only the setup step, and a re-add or an
upgrade (which wipes the packages) names that step instead of npm. A plugin with
no setup step keeps the npm line.
