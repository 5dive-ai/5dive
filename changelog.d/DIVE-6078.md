## Unreleased — fix(install): a detached install that finishes mid-poll reads installed, not interrupted (DIVE-6078)

`5dive agent install <type> --status` read the job's status file before asking
systemd whether the install unit was still alive. A job that finished between
those two reads paired its stale `running` record with an already-gone unit and
was reported as "install was interrupted before it finished" — the reboot/OOM
verdict — although it had installed cleanly. This held the v0.86.3 release
(nightly smoke, install-pi at 12s). The unit is now checked first; the job writes
its exit record before the unit ends, so the record read after it is final.
