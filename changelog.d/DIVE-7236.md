## Unreleased — fix(team): a team's lead stays admin under a template default, the owner's inbox opens on the first message, and the owner's "yes" is sent (DIVE-7236)

Found in a run of the dropshipping team on a box with no chat for the owner.

- **The lead of a hired team is admin again.** A template whose `defaults:`
  name a tier for every seat (`isolation: standard`) no longer takes root away
  from the lead under the box's `by-role` rule. Members keep the default, and a
  tier a seat names itself still wins.
- **`5dive task inbox --messages` and `--login` no longer crash** on the first
  message an agent sends the owner. Before, both stopped with "exited 1
  without reporting a reason" until something else had been read once.
- **The owner can answer an agent with one word.** `agent send <name>
  --from=owner --message=yes` from the owner's shell is no longer refused as an
  acknowledgement. An agent seat sending as the owner, or a send without
  `--from=owner`, is still checked.
