## Unreleased — feat(plugin)!: the dev-team tools leave the core for the devteam plugin (DIVE-6938)

PR delivery, graders, gate evidence, proof badges and the `gh`, `push` and `deploy`
rails are no longer in the CLI. They live in `devteam@5dive-plugins` (0.2.0), which
5dive's own boxes install; a box that hires agents for anything else never needs them.
The core loses about 14,200 lines of source, and `task ls` on a box without the plugin
runs in about two thirds of the time it took before (it no longer loads the grader
modules on every command).

- **Without the plugin**, `proof`, `gh`, `push`, `deploy`, their root-only halves and
  `task deliver|merge|merge-landed|merge-declined|unbind-pr|merge-audit|merge-unverified|merge-gate-selftest|grade-context|grader-tick|grader-replay`
  each print one line, `<verb> is in the devteam plugin: 5dive plugin install devteam`,
  and exit 2. `task done` on a row with a bound pull request refuses with the same
  line and leaves the row open.
- **The verifier loop stays.** `task done` on a row with no bound pull request hands a
  verifier row to its verifier (or closes any other row), `task reject` bounces it back
  with its FIX block, and `task answer` resumes the iteration-cap gate, with or without
  the plugin. So does the `Branch:` line parser that routes a gate on a branch-bound
  row to the lead (now in `src/lib/broker.sh`). Only their pull-request checks run in
  the plugin.
- **With it**, the CLI defines one stub per plugin function and reads the plugin's
  files the first time one is called in a run. The plugin must be the exact key,
  official, enabled, declare `core`, be writable only by root, ship all nine modules
  and define no core function; anything else and `5dive doctor` says why. A 0.1.x
  plugin is refused: upgrade it with the CLI (`sudo 5dive plugin upgrade devteam@5dive-plugins`).
- **The verbs stay reserved.** No other plugin may declare one, and `main` hands them
  to the pinned plugin before any plugin verb is looked up, because four of them are
  reached through NOPASSWD root grants.
- **The dispatch pace stays.** `_pace_*` and the account meter moved from
  `src/task/grader_pool.sh` into `src/lib/pace.sh`; the heartbeat paces every
  dispatch with it.
- **Harnesses:** 102 run from `5dive-plugins/tests/devteam/`: 90 moved there with the
  files they grade, and 12 are copied there whole while their core copy keeps only the
  core arms. The new `devteam-harnesses` job runs them against each pull request here,
  through the plugin's runner at its own pin, `DEVTEAM_PLUGINS_REF` (the shared
  `PLUGINS_REF` does not move with it). `tests/devteam_plugin_unit.sh`
  grades the no-plugin answers, every pin and six mutants.
