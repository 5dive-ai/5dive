## Unreleased — feat(local): the office server answers the 5dive app: people, join links, and which agents each member uses (DIVE-8807)

The office chat server now knows PEOPLE, not only devices. Each person has an owner or member role, and can have several devices. Devices paired before this release each become one person and keep every agent they had. Removing a person signs out all of their devices at once. The first owner still pairs with `sudo 5dive local pair --owner`.

Team → Invite in the app makes a one-time join link (`https://<office>/join#<code>`), valid for 24 hours. A member uses only the agents the owner gives them. "All agents" gives every agent, and a list gives exactly those agents. Someone with no agents granted sees no agents and gets refused on every other agent's chat, files and Needs-you. Owners see everything.

The office server answers the app's own paths under `/api/proxy/*` (who am I, team, chat with its live feed, files, agents, Needs-you and its answers, AI accounts, saved secrets, version) with the same shapes as api.5dive.com. Any other path is a 404 and is never sent off the box.
