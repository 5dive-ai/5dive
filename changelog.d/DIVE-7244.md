## Unreleased — fix(heartbeat): stop the false forge-merge alarm on boxes without the devteam plugin (DIVE-7244)

- **A box without the devteam plugin no longer logs "forge-merge sweep did NOT
  run" every heartbeat tick.** That sweep belongs to the plugin, so it is off
  there and now skips quietly, as the merge tick does. `5dive doctor` says the
  poll is off instead of "no reading yet".
- **A plugin that is installed but refused at load still logs the line, and now
  says why** (for example, a file writable by someone other than root), so the
  real failure no longer looks like the normal no-plugin state.
