## Unreleased — fix(ci): image builds and smokes retry a mirror or download hiccup instead of going red (DIVE-8088)

Installing a Hermes agent now retries its installer download when GitHub answers "too many requests" (429) or a server error, backing off for up to about 30 seconds, instead of failing the install. Nothing else changes on a box: the CLI's own `apt-get` steps in `install.sh` are unchanged. In CI, every image build and Ubuntu package step re-runs, after a wait, only when it failed on a download (a mirror 404, a dropped connection, a 429); any other failure fails at once, as before.
