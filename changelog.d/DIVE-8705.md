## Unreleased — fix(install): new OpenClaw agents get a working web chat again (DIVE-8705)

OpenClaw 2026.11.5 stopped its gateway from starting on a fresh install, so every OpenClaw agent created since 2026-11-17 had a dead web chat. New installs now use 2026.11.4, and a box that already pulled 2026.11.5 is moved back the next time the install runs. The nightly install check also stops counting a spent test key as a broken AI.
