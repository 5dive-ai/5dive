## Unreleased — feat(agent): `agent update --from-pack` brings a hired agent to its pack's version even where pack-sync leaves drift (DIVE-7275)

`5dive agent update <name> --from-pack[=<link|slug>] [--dry-run] [--no-restart]` re-applies a pack to one live agent without anyone holding root on the box beyond the CLI itself. The nightly `pack-sync` only replaces what it can prove the pack wrote, so an instructions file pushed by hand, or hired from an older pack, stayed behind for good. `agent update` replaces the pack's section at the head of the instructions file up to the CLI's own first block (the Telegram, model-choice, working-comms or team block, or a codex seat's baseline). That block and every line below it are kept byte for byte, and the old file is saved beside it as `CLAUDE.md.bak-pack-<time>`. Pack skills edited since install are reinstalled from the pack, keeping files the pack does not ship. Skills the pack does not list, the bot binding, chat, memory and login are not touched. The install record is rewritten, so the next nightly `pack-sync` takes over again. `--dry-run` prints the diff. An agent hired from no pack is refused, and so is a file with no CLI block to cut at.
