## Unreleased — fix(openclaw): set the gateway bind at agent start so OpenClaw web chat answers again (DIVE-7721)

OpenClaw 2026.10.10 refuses `openclaw config set` while the agent is running, so
adding the web chat channel no longer set the gateway to listen on loopback and
the chat answered "OpenClaw could not answer just now". The agent start script
now fills in a missing gateway mode and bind (local, loopback) before the agent
starts; a value you set yourself is left alone.
