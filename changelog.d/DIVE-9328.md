## Unreleased — chore(core): the first job at hire moves to the hosted plugin (DIVE-9328)

The owner's first job at hire only talks to 5dive's own servers as the box, so it left the public core for `hosted@5dive-plugins` (0.3.0, `5dive first-job`). Nothing changes for the 5dive API or for first jobs already running: `5dive agent first-job` and `agent _first_job_run` stay, and forward to the plugin.

New: `5dive task record-done` (root only) files a task that is born done, its fields as one JSON object on stdin. The plugin files the first job's task through it instead of writing the task database itself.
