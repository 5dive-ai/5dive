## Unreleased — fix(agent list): mark Claude Code on a custom base URL as deaf to app chat (DIVE-8137)

Claude Code turns its channels off whenever `ANTHROPIC_BASE_URL` points anywhere but Anthropic, so a Claude Code agent signed in through OpenRouter (or any other gateway) never hears app chat or Telegram. `agent list --json` still reported it as reachable. It now sets `health.deaf` to true for such an agent and adds `health.chat: {"ok": false, "reason": "openrouter"}` (or `"custom-base-url"` for other gateways), so the app can tell the owner why the agent does not answer. Every other agent reports `health.chat: null`.
