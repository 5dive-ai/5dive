## Unreleased — fix(agent switch): a Claude agent whose bot token lives only in the server's connector file switches to Codex and keeps its bot

`5dive agent switch <agent> --to=codex` refused with "has channels=telegram but no bot token on disk" on Claude agents whose Telegram bot was attached before the per-agent token copy existed. The token was on the server all along, in the connector file the agent's service loads and `agent telegram-info` reads; the switch only looked in the agent's own folders. It now falls back to that file, so the agent moves with the same bot. An agent with no token anywhere is still refused with the same sentence.
