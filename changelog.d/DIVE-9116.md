## Unreleased — feat(team): a premium team updates in place from a newer signed file, every agent keeps its memory (DIVE-9116)

Importing a newer premium team file over the installed team now updates it instead of leaving it alone: each agent's persona, skills, role text, title and recurring loops move to the new version, and its memory, channels, bot, logins, model and effort stay as they are. The file must be for the same buyer, and an older or the same version is refused unless `--allow-downgrade`. `5dive team update <team>` asks 5dive for the newest version this server's account may have and applies it the same way (an offline server imports the file by hand). `5dive agent update <name> --from-pack=<file.tar.gz>` now also takes a pack file on the box.
