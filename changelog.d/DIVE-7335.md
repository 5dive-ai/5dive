## Unreleased — fix(auth): a Codex or Grok agent signed in with no account starts signed in (DIVE-7335)

- `codex login` and `grok login` with no account save the login readable by its owner only, so a new agent on that login could not read it and came up on its own sign-in screen. The default login now gets a read for each agent of that type on no account (a per-agent permission, not a wider group). This happens when the agent is created, on `agent restart` (also for a Codex agent whose shared Codex account is empty), and when a dashboard sign-in finishes.
- The fix create's self-check suggests, `sudo 5dive agent restart <name>`, now repairs it.
