## Unreleased — feat(agent): in its Telegram groups an agent also answers to its card name (DIVE-6701)

A hired or imported agent with a Telegram bot now answers to its card name in its groups (the `name:` in its OpenAgent persona, so a `ceo` seat from a pack answers to "Tencha"), with no hand edit. The name is added to "Also answers to" (`groupsCallNames`) once: at `agent import`, when a bot is attached later with `agent config … channels=telegram`, and by `self-update` for agents hired before. `5dive agent telegram-access seed-names [<name>]` runs it by hand. A name already on the list in any case is not added twice, the seat id is never added, a full list of 10 is left alone, and a name the owner removed is not added back (the offer is remembered outside access.json, which the plugin rewrites).
