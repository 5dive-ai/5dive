## Unreleased — fix(skill): never empty a seat's skill on a failed refresh; list fails on a refused read (DIVE-7860)

The nightly skill refresh could leave a Grok seat with EMPTY skill folders when its
skills folder was owned by root: the seat's install deleted the old files, could not
finish, and exited 1, every night. The skills folder now goes back to the seat before
and after each install, the new copy is staged and swapped in only once complete (a
failed install keeps the old one), and the installer's error line reaches the caller
and the audit row.

`5dive agent skill <seat> list` now fails with "needs root" (`ok:false`) when it cannot
read the seat, instead of answering "no skills installed".
