## Unreleased — feat(grok): chat with a Grok agent in the 5dive web chat (DIVE-7347)

- A Grok agent can now take the web chat: `5dive agent config <name> set channels=<current>,dashboard` (the app's one-tap Enable chat) and `agent create --type=grok --channels=…,dashboard` are accepted instead of refused. A self-hosted chat-only box gives a new Grok agent the web chat by default, as it does Claude and Codex agents.
- At boot the agent's Grok config runs the dashboard plugin's Grok bridge (dashboard plugin 0.5.14), which types each web-chat message into Grok and sends back Grok's own answer, spoken for a voice note. Turning the chat off removes it again.
- A Grok agent with both Telegram and the web chat now gets its Telegram bridge too; it was wired only when Telegram was the agent's sole channel.
