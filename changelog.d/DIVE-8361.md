## Unreleased — secret https: a self-hosted box's free <name>.5dive.app comes first (DIVE-8361)

A self-hosted server linked to 5dive.app now gets its own `<name>.5dive.app` (the link
script keeps it in `/etc/5dive/app-name`, and 5dive.app points it at the server's
address). `5dive secret https` tries that name FIRST, before the IP certificate and
sslip.io: a normal certificate for one name, with the secret page and the browser's
sign-in screen as paths on it. New: `sudo 5dive secret https enable --via=5dive-app`.
A name file in any other shape is ignored.
