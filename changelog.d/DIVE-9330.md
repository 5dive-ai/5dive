## Unreleased — chore(core): `team update` moves to the hosted plugin (DIVE-9330)

`5dive team update <team>` still brings a premium team bought from 5dive to its newest version, but the code that asks 5dive's servers for it left the public core for `hosted@5dive-plugins` (0.5.0). Core still checks and applies the file, so `5dive team import <newer file>` works exactly as before, offline too.

The install now adds that plugin to any server with a 5dive sign-in and a premium team on it, not only to servers 5dive built. The tool that makes premium team files left the core with it.
