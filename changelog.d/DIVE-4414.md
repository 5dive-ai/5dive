## Unreleased — fix(import): apply an explicit isolation tier to marketplace packs (DIVE-4414)

`5dive agent import <pack-or-slug> --isolation=admin|standard|sandboxed` now forwards the explicitly requested tier to `agent create` instead of silently retaining the pack manifest's tier. Imports without the flag continue to preserve the manifest value, persona imports retain their existing default, invalid tiers fail before staging or creation, and the import usage text now documents the flag.
