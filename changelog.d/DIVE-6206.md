## Unreleased — fix(skill): clear a half-extracted npx cache dir and retry the add once (DIVE-6206)

`npx` reuses `~/.npm/_npx/<hash>` whenever the dir exists, so an install killed mid-extract (the
180s timeout at seat creation) left a partial tree that failed every later `agent skill add` and
the nightly skill refresh with `ERR_MODULE_NOT_FOUND`. The add now spots that error under the
seat's own `~/.npm/_npx/<16-hex>/`, removes that one dir and retries once. Any other failure
deletes nothing, and a symlinked cache dir or `~/.npm` is never followed into a delete.
