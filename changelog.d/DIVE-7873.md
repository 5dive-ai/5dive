## Unreleased — feat(backup): every box backs up its agents to a second provider each night, encrypted with a key only the owner holds (DIVE-7873)

`5dive backup` sends an encrypted, deduplicated copy of the box's agents (homes,
memory, chats, registry, task board, settings) to Cloudflare R2 every night. The
key is made on the box and sent once to the owner's Telegram as a recovery code;
5dive never holds it and cannot open the backups. `5dive backup restore
--code=<code>` brings a box back on a fresh server. The first nightly run sets a
box up by itself; `5dive backup status` shows the last result.
A fresh server whose owner already has a backup never makes a second key: it
waits for `5dive backup restore --code=<code> --from=<box-N>`, or for the owner
to choose `5dive backup enable --new-key` if the old code is lost.
