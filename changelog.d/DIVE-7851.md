## Unreleased — fix(auth): sign-in installs a missing AI runtime first (DIVE-7851)

A self-hosted box ships Claude Code only. The app's one line for ChatGPT,
`sudo 5dive account add chatgpt && sudo 5dive agent auth login codex --auth-profile=chatgpt`,
failed on every fresh box with `codex not installed`, and so would the same line for
Grok or any other non-Claude AI. `agent auth login` and `agent auth start` now run the
runtime's installer first, the same way `agent create`, `import` and `switch` already
do, then go straight on to the sign-in. A failed install stops before the sign-in and
names the retry (`sudo 5dive agent install <type>`); a type with no installer is
refused as before.
