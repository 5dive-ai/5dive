## Unreleased — fix(openclaw): a model set inside an OpenClaw agent survives its restart (DIVE-7911)

An OpenClaw agent switched to a cheaper model with `openclaw models set` went back to its
account's model (Sonnet) on the next restart, because the start copied the account's model over
the agent's whenever the two differed. The owner paid for Sonnet while the agent showed Haiku.

The start now copies the account's model only over a model the account put there. A model set in
the agent itself is kept, and the start says so. An agent that never chose its own model still
follows its account (a new `agent auth login` still reaches it), and an agent with no model, or
OpenClaw's built-in default, still gets its account's. `agent config <agent> set model=` already
held across restarts and still wins over both.

The nightly install check now fails an OpenClaw run whose model pin does not hold after the
restart, or whose turn names Sonnet or Opus.

`tests/dive7911_openclaw_model_pin_unit.sh`: 15 arms, 3 of them red with the fix removed.
