## Unreleased — feat(task): a secret gate alert points to the app paste; resume ping names the file (DIVE-5319)

An owner with no shell had no way to answer a secret gate: the Telegram alert
only offered an on-box `sudo 5dive secret write` command. The alert now leads
with the paste in the 5dive app (the task's card on the dashboard, or My team
in the Telegram Mini App), which writes the value straight to the box, keeps
the on-box command as the alternative, and still says never to paste it in the
chat.

When the gate named a key and connector, the agent's resume ping now says
where the value landed (`<KEY> is in /etc/5dive/connectors/<connector>.env`)
instead of "where it was placed", so the next turn loads it without guessing.
