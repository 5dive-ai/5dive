## Unreleased — fix(heartbeat): an owed restart is no longer held forever by Claude Code's "/clear to save N tokens" hint (DIVE-6050)

Claude Code 2.1.296 prints `new task? /clear to save N tokens` between the
status line and the composer once a session is large. The heartbeat read that
hint as the status line, so a seat that had finished its turn with one stray
background shell read as mid-turn forever. Its owed restart never fired, and the
DIVE-4298 done-with-shells checks never fired either. The status-line walk now
skips the hint. A seat that owes a restart and has no open row now also gets a
pane-free pass: agent-written shells older than 24h in the seat's own cgroup are
reaped by PID (`HEARTBEAT_OWED_SHELL_MIN_AGE`), still never a `FIVEDIVE_KEEP_ALIVE`
one and never during a visible running turn. Every tick logs one line saying why
nothing was reaped.
