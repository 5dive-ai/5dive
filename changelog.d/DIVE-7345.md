## Unreleased — fix(plugin): refresh a set-up voice engine on upgrade when no setup was recorded (DIVE-7345)

- A box whose voice was set up with `5dive voice setup` now gets the new voice engine when the voice plugin upgrades. Before, the upgrade said "setup owed" and left the old engine in place, so self-hosted boxes never got voice 1.11.3's retries against Microsoft's free voice.
- Boxes already on voice 1.11.3 with the old engine are refreshed on the next plugin auto-upgrade. A box that never set up voice is still only listed as owed; nothing starts a setup nobody ran.
