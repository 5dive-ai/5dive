## Unreleased — feat(machine): `5dive machine add|rm|ls` attaches any machine you can SSH into (DIVE-5622)

`sudo 5dive machine add <name> <user@host[:port]>` lets every agent on the box reach that machine as
`ssh <name>`. It makes the box's keypair once (root:claude 0640), adds a `Host <name>` block to
`/etc/ssh/ssh_config.d/50-5dive-machines.conf`, keeps one line in `/etc/claude-code/CLAUDE.md` naming
the machines, and prints the box's PUBLIC key to put in the machine's `authorized_keys`. No password is
taken and nothing is provisioned. `machine rm <name>` forgets it here and never touches the machine;
`machine ls` reads the ssh config (no database).
