## Unreleased — ci(init-smoke): every night, take each agent type from a fresh Ubuntu through `5dive init` to its first reply (DIVE-7337)

A new nightly check does what a new customer does: a fresh Ubuntu 22.04 and 24.04 server, the installer, `5dive init` answered on a real terminal, then one question to the new agent. It passes only when the agent itself answers correctly. It covers Claude Code, OpenClaw, Hermes (sandboxed and standard) and Codex, each on the cheapest model. A failure holds the next release, the same way the install check does. Until the test keys are added to the repository, the check still runs the installer and the setup wizard every night and reports the reply as skipped.
