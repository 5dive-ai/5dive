## Unreleased — fix(agent): `agent send` no longer says "sent" for a message left typed in an idle agent's input box (DIVE-8957)

- A message long enough to fill an agent's input box (roughly 450 to 800 characters on a phone-sized window) made the box scroll, and the delivery check then read the box as empty. A lost Enter was never retried, and two «ready in prod» pings sat unsent for up to 90 minutes. The check now sees a scrolled box, so the retry Enter fires, and the clean-up before a send empties a tall leftover draft.
- `agent send` now exits 12 (`unconfirmed`) when the message was typed but could not be confirmed as sent, so scripts that only read the exit code retry instead of logging success. The receipt is unchanged (`sent:false` with a reason). A message queued for a busy agent still exits 0.
