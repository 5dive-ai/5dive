## Unreleased — feat(agent): one switch for how an agent answers in its groups, when called by name or every message (DIVE-6675)

`5dive agent telegram-access groups <name>` reads how the agent answers in its Telegram groups, and `--answer=name|every` sets it: "when called by name" (the default) or "every message". It sets `requireMention` on every approved group and stores `groupsRequireMention` in access.json, which the telegram plugin (0.5.103+) gives a group added later and uses for its hello line. The plugin re-reads access.json per message, so no restart. This is the box half of the app setting "In groups, answer".
