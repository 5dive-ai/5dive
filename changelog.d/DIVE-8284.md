## Unreleased — fix(agent): a locked-down agent with web chat can hear the app (DIVE-8284)

A sandboxed agent with web chat turned on never heard the app: it has no sudo,
and since 0.78 the web chat reaches the app (and opens encrypted messages) only
through two root helpers that only standard agents were allowed to use. Turning
on web chat for a sandboxed agent now gives it exactly those two helpers, which
act for that agent alone, and turning it off takes them away. Existing sandboxed
agents with web chat get them on the next update. `agent info` shows this as
`chat-only` (still sandboxed).
