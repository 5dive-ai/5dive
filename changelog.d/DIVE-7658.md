## Unreleased — feat(channels): Microsoft Teams, each agent its own contact (DIVE-7658)

`teams` is a channel now: `5dive agent config <agent> set channels=…,teams` and
`agent create --channels=teams` install the new teams plugin (teams@5dive-plugins),
the agent starts with it, and managed settings allow it. The setup lives in the
plugin: `sudo 5dive plugin install teams`, then
`sudo 5dive agent teams connect <agent> --app-id=<id> --tenant-id=<id>`.

Teams messages go through Microsoft's cloud, so local-only mode keeps it shut by
default: the channel and `agent teams connect` are refused with one line. The firm's
IT can open Teams alone with `sudo 5dive config local-only allow teams` (and shut it
with `deny teams`): every other refusal holds, `local-only status` says whether Teams
is open, and `local-only check` counts the teams plugin's connections as allowed and
any other outside connection as a LEAK. `local-only off` forgets the opening, so the
next `on` starts fully offline. Claude Code agents only for now.
