## Unreleased — fix(grok): `config set model=` changes a Grok agent's model, and `agent ask` reads its reply (DIVE-7340)

- `5dive agent config <name> set model=<id>` on a Grok agent now writes the model where Grok reads it (`[models] default` in its config) and checks it back, instead of saying OK and changing nothing. Telegram's /model on a Grok agent uses this same command.
- `5dive agent ask` on a Grok agent returns its answer. Grok never shows the answer on screen, so ask now reads it from Grok's own session file; before, every ask timed out and blamed the reply format.
- On Grok's sign-in screen, `agent ask` and `agent send` now refuse and say the agent is not signed in, instead of typing the question into that screen and reporting OK.
