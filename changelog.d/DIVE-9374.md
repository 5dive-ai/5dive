## Unreleased — fix(cli): `--help` works on the host, route, pkg and usage subcommands (DIVE-9374)

`5dive host unit repoint --help` (and `-h`), `route add --help`, `pkg install --help`, `usage --help` and `usage loops --help` used to fail with "unknown flag" or "must run as root" instead of saying how to use the command. Each now prints its usage and exits 0, as the agent, account and task subcommands have since DIVE-569. `5dive host --help` and `5dive host unit --help` print the full usage instead of a one-line error. `usage loops` is now listed in `5dive --help`.
