## Unreleased — chore(marketplace): a DigitalOcean 1-Click image and a Linode Marketplace app for 5dive (DIVE-6801)

`marketplace/` holds what we submit to two hosting marketplaces, so someone who rents a server can
pick 5dive from the hoster's app list. Nothing is listed yet: the listing copy waits on a yes.

- `marketplace/image/`: Ubuntu 24.04 plus `install.sh` at build time; `cleanup.sh` strips every
  per-server key, token and id and fails the build if one is left; `firstboot.sh` (cloud-init, once
  per new server) updates the CLI and redoes the per-server install steps; the login shows one
  line, how to link the server at 5dive.ai/self-host, until it is linked.
- `marketplace/digitalocean/5dive.pkr.hcl`: Packer build that ends with DigitalOcean's own
  clean-up and image check, pinned by commit and sha256.
- `marketplace/linode/`: the Ansible app in the layout of Akamai's marketplace-apps repo.
- `tests/marketplace_image_unit.sh`: the clean-up, the login line, first boot and the wiring.
