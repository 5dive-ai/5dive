## Unreleased — fix(pack): a pack skill arrives whole, with its scripts and references, and existing agents get the missing files back (DIVE-6796)

Importing a pack from the registry copied only each skill's `SKILL.md`. A skill's script (`mail/mail.py`, `heroui-react/scripts/*`) and its `references/` and `evals/` never reached the agent, so "connect my mail" could not run. A re-import or refresh also deleted any file pushed by hand. The public registry has 295 such files in 25 of 36 packs.

- The registry fetch now reads the registry's git tree once per pack and downloads every file of each listed skill, executable where git says so. Each path from the listing is checked: plain name segments only, no `..` or `.`, at most 8 levels deep, never a symlink, at most 200 files and 5 MB per file. If the tree can't be read (for example, rate-limited), the import falls back to `SKILL.md` alone, as before, and never fails.
- Reinstalling a skill keeps any file the new bundle lacks instead of wiping the folder. Only regular files carry over, read as the agent; a planted link is dropped.
- `agent pack-sync` (run by the nightly box update) copies each existing agent's missing pack-skill files back in. It never overwrites a file the agent has, including an owner's edit, and it doesn't restart the agent. The write runs as the agent. The result reports these skills as `backfilled`.
