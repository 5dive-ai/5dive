## Unreleased — feat(agent): `agent logs <name> --screen` prints one frame of the agent's own window, for the app's live Screen view (DIVE-7652)

The app's "What it's doing" sheet gains a Screen view: the agent's real terminal
window (Claude Code, Codex and so on), live and view-only. It polls this verb about
once a second.

`--screen` is a `tmux capture-pane -e` of the visible grid, with colours, plus the
pane's size (`cols`, `rows` in JSON). It never attaches: an attached client would
resize the agent's own session to the phone's width (`window-size latest`, the
trade `5dive wall` accepts), and an attach is one stray key from a Ctrl-C. Root
only, like reading the seat's journal; admin seats re-exec through sudo.
