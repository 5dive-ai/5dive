## Unreleased — fix(hermes): new Hermes agents start, and init asks for the key once (DIVE-7330)

- New installs get Hermes 0.21.5, pinned (installer and code from one commit). Hermes 0.21.6 and later keep their dependencies per home folder, and every agent has its own, so each new Hermes agent stopped at start with "no dependency environment is committed for this install".
- `5dive init` → Hermes asked for the API key a second time on a real terminal and looked frozen. The key is now handed over once, from 5dive's own prompt.
- A new Hermes agent on the box's own Hermes login is no longer pointed at the ChatGPT provider in create's output.
- create's self-check now runs Hermes as the agent and reports a Hermes that does not start, and the nightly harness smoke runs every agent type's binary as the agent too.
