## Unreleased — feat(agent): agent list flags a seat whose Claude org blocks its channel plugins (DIVE-5925)

A seat signed into a Claude Team or Enterprise account can get its messages and never answer:
the org's admin set its own list of allowed channel plugins, Claude Code caches it at
`~/.claude/remote-settings.json`, and that list wins over the box's managed settings.

`agent list --json` now reports `orgBlocksChannels` on each row, for example `["dashboard"]`:
the seat's own channel plugins that the org policy leaves out, or all of them when the org
turned channels off. It is `null` for a personal account (`{}`), a missing or unreadable file,
an org with no channel rule, and a list that includes the seat's plugins. The flag clears on
its own once the admin allows the plugin and the agent restarts.
