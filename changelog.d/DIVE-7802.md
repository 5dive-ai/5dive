## Unreleased — feat(grok): Grok agents work on every server with no opt-in step; the owner can still turn them off (DIVE-7802)

Picking Grok on a self-hosted server used to stop at "Grok is off on this server … run: sudo 5dive
grok enable", and owners have no terminal. Grok is now on by default: `agent create --type=grok`,
`agent switch --to=grok` and `5dive init` go straight through and show one note line — "Grok's tool
sends your agent's notes and chat turns to xAI after every turn." `5dive grok disable` is the
owner's off switch (it writes `/etc/5dive/arm/grok-off`, which create, switch and init respect);
`grok enable` removes it, with no y/N and no terminal. The old opt-in marker
(`/etc/5dive/arm/grok-unfreeze`) is no longer read, so managed boxes that carry it are unaffected.
