## Unreleased — feat(agent): `export --memory` reads the seat's OWN memory store, and import converts it across harnesses (DIVE-4541)

`_pack_memory_dir` hardcoded `~/.claude/projects/<slug>/memory`, so
`5dive agent export codex --memory=raw --audience=self` answered
`agent 'codex' has no persona memory to export` while 1.8 MB of memory sat in
`~/.codex/memories`. The claude path was never a universal default — it is one harness's
answer — so the store is now resolved from the seat's registry type: claude keeps its
path, codex reads `~/.codex/memories`, and any other harness gets an honest "no store
5dive knows" that names the type, never a claude path it does not use.

Moving memory between the two is a **conversion, not a copy**, and both halves needed it:

- **Distilled from a codex seat.** Codex keeps three whole documents, not one file per
  fact, so the deny-by-default allowlist — which keys on each fact's `metadata.type` —
  could not decide anything about them and would have excluded the lot. The draft phase
  now converts the store into frontmattered atoms first, one per `# Task Group:`,
  carrying only the `## Reusable knowledge` and `## Failures and how to do differently`
  subsections. The user profile, the stated preferences and the raw thread notes do not
  enter the draft, and the ordinary allowlist then holds over the result unchanged —
  including on seal.
- **Raw, and import onto a claude seat.** A raw pack carries the codex documents verbatim
  and the manifest records `includes.memoryShape: "codex-docs"` so a later importer knows
  what it is holding. Import onto a claude seat converts them into atoms and regenerates
  a router-shaped `MEMORY.md`; onto a codex seat it copies them into `~/.codex/memories`.
  The measured store converts to 104 atoms — whose full-description index came to 23 KB,
  over the always-loaded limit, where the loader drops the **tail with no error**. So the
  index writer has a budget and degrades in two declared steps (descriptions dropped,
  then the listing cut with a line saying how many atoms it did not name). A copy would
  have landed a 143 KB `MEMORY.md` that reads as success and is silently truncated.

Graded by `tests/pack_cross_harness_memory_unit.sh` (36 arms), each of which was shown to
red under a reverted hunk.
