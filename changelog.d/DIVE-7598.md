## Unreleased — feat(offline): install a fully local server from a USB stick with no internet (DIVE-7598)

A new Ubuntu 24.04 server that has never been online now becomes a local-only 5dive box from one
file: `sudo bash 5dive-usb-<version>.run`. Each release publishes it next to the update file,
with its `.sha256`.

- **One file, one command.** It holds the signed update file and the system packages a fresh
  server may lack, and installs only the ones the server does not already have. Then the same
  installer as `curl install.5dive.ai` runs a fresh install from the file, with no connection to
  anything. 5dive's update key is saved on the box, and local-only mode is on before the first
  file is copied.
- **Claude Code comes from Anthropic, not from 5dive.** Its licence does not let 5dive hand it
  out. Put Anthropic's `claude` and `manifest.json` next to the file on the stick. The installer
  checks it against Anthropic's checksum before anything is installed, and puts it where
  Anthropic's own installer would.
- **`config local-only off` keeps the office chat running.** It only answers on the office
  network, so going online (for a Claude subscription) exposes nothing. Before, turning the switch
  off also stopped the chat, and it had to be started again by hand.
