## Unreleased — fix(agent switch): a seat switching itself detaches instead of dying halfway (DIVE-8371)

An agent that ran `sudo 5dive agent switch <itself>` used to stop its own service with the switch
still inside it, so the switch died halfway and the agent stayed down until someone started it.
Now the switch sees it is running inside the seat it switches, hands itself to a separate service
and returns at once: the agent is back on its new AI in under a minute. It is told to write its own
handoff note instead of being asked for one. Switching another agent, or from the dashboard, is
unchanged.
