## Unreleased — fix(init): a fresh box's first screens point at `5dive init` and stop calling a working agent broken (DIVE-7333)

- The installer's last screen names one next step, `sudo 5dive init`, and its health check is one line (the full report is still `sudo 5dive doctor`).
- `5dive agent list` no longer flags an agent made a minute ago as OVERDUE; a never-run agent is flagged once it is older than its stall window.
- An OpenClaw or Hermes agent's Telegram allowlist is read where those runtimes keep it, so a paired agent is not reported as deaf, and an OpenClaw agent that holds its own key is not reported as a permissions fault or shown as degraded.
- `5dive agent ask` names a refused turn ("Credit balance too low", a bad key) as an account problem instead of a formatting one.
- `5dive agent config <name> set model=<id>` works for OpenClaw and Hermes agents; the choice survives restarts.
- `5dive init` asks you to turn Grok on, with its warning, before it installs Grok or opens its sign-in; say no and you pick another agent type. It no longer installs Grok and signs you in only to refuse at the end.
