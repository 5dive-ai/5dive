## Unreleased — feat: a lead agent makes a custom agent from what its owner needs, from chat (DIVE-5722)

lodar, 2026-10-06: "should Olivia and other leaders have a skill to hire agents or even create
custom agent for human needs". Catalogue hiring already worked from chat; a custom agent could
only be made by the owner in the Mini App.

`5dive hire-link --create --name=<Name> --description=<the need>` runs the Mini App's own create
for the box's owner (5dive-api `POST /server/custom-agents`, authenticated by the box identity).
The agent writes the name and description from the conversation; the skills, role, voice and gender
are picked by 5dive exactly as in the Mini App, never by the agent. It hires nothing. It prints the
draft (name, role, skills) and the agent's card link, which opens the Mini App on its Hire card.

The hire stays the owner's. On a standard-tier seat the owner taps Hire on the card. An admin-tier
seat hires on the owner's clear yes in chat with `5dive hire-link custom-<id> --hire`, which is the
Mini App's Hire onto this box: it waits through the import (about 90 seconds) and prints the new
agent's name. A standard-tier seat is refused `--hire` before any call, both on its own and behind
the root grant it holds for `hire-link`. `5dive hire-link custom-<id>` prints that card link again.

A partner's box is refused all of it; partner agents send a card link and never hire from chat.
`5dive hire-link <slug>` for a name outside the catalogue now names `--create` instead of the web
dashboard, which has no custom-agent card. The box's projects CLAUDE.md gains one line for it and
stays at its 450-word cap (`uv tool install`, `5dive org tree` and three filler words dropped).
