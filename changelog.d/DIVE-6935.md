## Unreleased — feat(plugin): the devteam plugin can supply the dev-team tools, nothing removed yet (DIVE-6935)

First step of moving PR delivery, graders, gate evidence, proof badges, `gh`, `push` and `deploy` out of the core into one plugin, `devteam@5dive-plugins`. With that plugin installed, 5dive reads the plugin's copy of each of those modules straight after its own, so the plugin's code is what runs. Only that exact plugin may do this: it must be official, enabled, declare the new `core` capability, and every file it ships must be writable by root alone. Any other plugin declaring `core` is refused at install. A box without the plugin behaves exactly as before. `5dive doctor --category=plugins` says which copy this box runs, and `FIVEDIVE_DEVTEAM=0` skips the plugin for one run. The core copies are deleted in a later release, once our own boxes run green on the plugin.
