## Unreleased — docs(local): the USB install's "add an agent" line works and puts the agent in the office chat (DIVE-7659)

The guide's USB section told you to add an agent with `--base-url` and `--model` only, which
`agent create` refuses (a claude agent on your own AI needs `--auth-profile`), and even a working
create would have left the agent with no chat. It now shows the office panel's own call: save the
AI once with `account add office-ai`, then
`sudo 5dive agent create <name> --type=claude --auth-profile=office-ai --channels=dashboard`.
The "New agent" hint that `account add --provider=custom` prints adds `--channels=dashboard` too,
for every agent type with a chat.
