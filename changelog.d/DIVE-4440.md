## Unreleased — fix(tests): a second EXIT trap silently unarmed HARNESS-RC, and the contract could not see it (DIVE-4440)

`tests/codex_channel_health_unit.sh` registered a second `trap ... EXIT` for its
tempdir cleanup, 167 lines below the `HARNESS-RC` trap at the head of the file.
bash keeps only the LAST trap per signal, so the cleanup replaced the marker and
the harness has printed **no `HARNESS-RC` line at all** since it landed — on green
runs as well as red ones. A harness that exits without naming its return code is a
check whose all-clear and whose breakage look the same from outside CI.

`tests/harness_rc_corpus_contract_unit.sh` exists to prevent exactly this and did
not: it greps for one line carrying the marker and stops, so a file may arm the
trap on line 29, unarm it on line 196, and stay green forever. Its own FIX text
already stated the rule — *"bash keeps only the LAST trap registered per signal …
never left as a second trap alongside it"* — which is prose, not a guard.

- The cleanup is folded into the marker trap, so the two cannot compete.
- **The contract is armed** (7 arms → 14): no harness may register a top-level
  `EXIT` trap that lacks the marker. Strengthened, not relaxed.

Telling a top-level trap from a nested one is the hard part, not detecting one.
Five other corpus files carry a second `EXIT` trap that is correct — one inside a
`( )` subshell, four inside quoted heredocs or awk-built fixture text this shell
never executes — and a line-grep reds all five. All six candidates were run: one
`HARNESS-RC` line each except the offender's zero. A detector that reds correct
files teaches authors to route around it.

The discriminator parses with bash itself, and carries one correction found while
building it: an **unterminated heredoc is a warning, not an error**, so
`head -n <line> file | bash -n` exits 0 and an rc-only prefix parse calls a line
inside generated fixture text "top level". Completeness here requires rc 0 **and**
empty stderr. The shared library keeps its old behaviour: its caller asks about a
terminal verdict line, where no heredoc can be open, and widening a working
instrument mid-ship to suit a new caller is how a control acquires behaviour
nobody graded.
