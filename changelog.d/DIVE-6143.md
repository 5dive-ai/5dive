## Unreleased — feat(machine): `machine add --note` records what an attached machine is for (DIVE-6143)

`sudo 5dive machine add <name> <user@host[:port]> --note="<what it is for>"` stores a one-line note
(up to 300 bytes, no backticks, `<` or `>`) as a comment in that machine's `Host` block. The machine then
gets its own line in `/etc/claude-code/CLAUDE.md`, so an agent knows when to reach for `ssh <name>`,
not only that it exists. `machine ls` and `--json` show the note (`note: null` when there is none),
re-adding without `--note` drops it, and `machine rm` removes it with the block. A box with no notes
keeps the existing CLAUDE.md line unchanged. Only Claude Code seats read that file; other seat types
find their machines with `5dive machine ls`.
