## Unreleased — fix(voice): `auto-voice --status` says broken when the voice key cannot pay for hearing (DIVE-8559)

When a box hears voice notes through OpenRouter and its key has run out of credit (or is capped below OpenRouter's $0.50 floor for audio), every voice note failed while `5dive plugin auto-voice --status` still said "on". The status now asks OpenRouter's free key check and reads "broken", naming the fix: switch hearing to the box's own whisper (`sudo 5dive voice config set stt_backend local`) or add credit. `--on` no longer re-runs setup for this case, since setup cannot fix a key that cannot pay.
