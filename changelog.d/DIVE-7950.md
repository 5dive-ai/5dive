## Unreleased — refactor(crew): crew leaves the core CLI for an optional plugin, its feed receipt off by default (DIVE-7950)

- **`5dive crew` moved to the crew plugin.** `sudo 5dive plugin add crew@5dive-plugins` brings it
  back with the same subcommands (install, secret, run, show, list, uninstall). A box without it
  answers `5dive crew` with one line: `crew is a plugin now: sudo 5dive plugin add crew@5dive-plugins`.
- **A default install no longer posts anything to the 5dive feed.** In the plugin, `crew run` sends
  its signed work receipt only with `--receipt`; SECURITY.md's "what leaves your server" list drops
  the `crew run` line. Crews already installed under `~/.5dive/crews` keep working unchanged.
