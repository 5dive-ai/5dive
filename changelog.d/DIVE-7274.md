## Unreleased — fix(secret): a saved login under the wrong Vault key is always refused, never typed in as garbage (DIVE-7274)

Saved values are now stored as `v2:`: a known check sits in front of each value before it is encrypted, and reading one requires it back. Before this, about 1 read in 256 under another box's key decrypted to garbage instead of failing, and the browser could have typed that garbage into a site. Existing `v1:` values still read (with a text check that refuses garbage) and are rewritten as `v2:` the first time any saved verb runs as root. A `v1:` value saved under another box's key is kept as it is and still asks the owner to save it again.
