## Unreleased — fix(release): canary boxes take only a tag cut from main; old-org fallback removed; signing keys behind a protected environment (DIVE-7973)

- **A canary box installs only a release tag that was cut from main.** Before taking the newest tag,
  the installer checks it has the release-cut shape (a bundle commit and a version commit on top of a
  commit main contains). A tag that does not is skipped and the previous release is taken; if GitHub
  cannot confirm it, the box keeps the version it has. The fleet pin applies the same rule.
- **The GitHub org is `5dive-ai`, fixed.** The installer, `5dive self-update` and the plugin refresh no
  longer probe for the org and fall back to the pre-rename name. `GH_ORG` still overrides.
- **Release signing runs in a protected environment**, and `oven-sh/setup-bun` is pinned to a commit.
- Dependabot security PRs are titled `fix(deps): …`.
