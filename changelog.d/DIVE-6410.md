## Unreleased — feat(isolation): a box-wide tier for new seats, and `agent grant <name> admin` (DIVE-6410)

`5dive config seat-isolation=admin` makes every new agent on the box admin when its create or import names no `--isolation`, including a pack whose manifest names a tier. An explicit `--isolation` still wins, and `default` restores the old rule (first seat admin, later seats standard). Partner boxes whose every seat is admin get it at build.

`5dive agent grant <name> admin` re-isolates one existing seat to admin, rendered as `agent create --isolation=admin` renders it: the managed sudoers drop-in, the registry and env label, and the claude-keys group. It works from standard or from managed root (so `grant root` can now be narrowed back), and refuses a sandboxed seat or a sudoers file the CLI did not write.
