## Unreleased — feat(agent): names an agent also answers to in its Telegram groups, in any language (DIVE-6684)

`5dive agent telegram-access groups <name> --names="Оля,Liv,奥利维亚"` stores the names the agent also answers to in its groups as `groupsCallNames` in access.json; `--names=` clears them. The telegram plugin (0.5.105+) matches each like the agent's display name. A name is 2-32 letters, marks, spaces or hyphens with at least 2 letters a word (so "a -" is refused), at most 10, so a pattern is refused before anything is written. The read now returns `names` beside `answer`, `groups` and `mixed`, and a write that sets only names leaves the groups as they were. It can be combined with `--answer=`. The verb now reads and writes access.json as UTF-8 and keeps non-Latin text unescaped. This is the box half of the app field "Also answers to".
