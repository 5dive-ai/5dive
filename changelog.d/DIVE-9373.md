## Unreleased — fix(agent): `agent send` / `_deliver` no longer exit 12 for a message the seat already received (DIVE-9373)

When the composer still looked full after two Enters, `agent send` and the scoped `_deliver` exited 12 ("typed but NOT submitted, retry later") even if the target seat had already taken the message and started its turn, so a caller that trusts the exit code sent it again and the seat ran the job twice. Before reporting a miss, the shared send path now checks the seat's own transcript for this exact message (a new user record in the same session, or the first record of a new session). If it is there, the send exits 0 with `sent:true` / `delivered:true`. A real miss still exits 12 with the same reason as before.
