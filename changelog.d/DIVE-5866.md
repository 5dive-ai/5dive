## Unreleased — fix(self-update): an unchanged skills re-pull no longer restarts every agent (DIVE-5866)

The nightly self-update only restarts an agent when its payload (skills, plugins,
CLAUDE.md, settings) changed. That check hashed `.skills-manifest.json`, and every
skills re-pull stamped a fresh `installed_at` into it, so the check never matched and
every agent was restarted every night, dropping any live conversation, even with zero
skills changed and the same build.

The fingerprint now leaves the manifest out (it is provenance; no agent loads it), and
all four manifest writers keep an entry's `installed_at` when its source, commit and
content hash are unchanged, so the manifest also says when a skill really changed. A
changed skill body still moves the fingerprint and restarts the agent.
`tests/self_update_restart_predicate_unit.sh` replays two unchanged re-pulls through the
shipped manifest block and asserts the fingerprint is equal (red on the old tree).
