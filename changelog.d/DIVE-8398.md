## Unreleased — feat(heartbeat): gate-reminders=daily[@HH], one owner reminder batch a day (DIVE-8398)

An owner with many open questions got a separate reminder for each one, spread across the day. `sudo 5dive config gate-reminders=daily@9` now sends every open question in one message a day at 09:00 UTC (plain `daily` means 09). Urgent questions keep their own clock, and a box that does not set it is unchanged.

There is no `off`: changing the setting sends the owner one message naming the agent that changed it. `FIVEDIVE_GATE_RENAG=0` in root's cron is still the only full silence.
