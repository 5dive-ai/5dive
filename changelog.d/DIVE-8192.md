## Unreleased — fix(acp): `5dive acp` runs on node when bun is missing

`5dive acp` used to need bun, so on a machine without it an ACP client (Zed, JetBrains, Buzz) spawned it and got nothing back. It now falls back to node 22.18 or newer when there is no bun, which is also what the ACP registry's listing check runs on. Bun is still used first wherever it is installed. With neither, the error names both and how to install one; `ACP_NODE_BIN` and `ACP_RUNTIME=bun|node` pick a runtime explicitly.
