## Unreleased — fix(share): a fresh agent hired from a marketplace pack can be shared again (DIVE-8507)

Sharing an agent such as Olivia was refused with "private detail" for text the owner never wrote. The check that leaves our own unedited default skills out of the scan now computes their fingerprint the same way the skills tool does, so an untouched 5dive-cli or compile-knowledge skill is skipped again (one edited byte still gets it scanned). A link to our own site (5dive.com, 5dive.ai) no longer counts as a leak. The pack text that offers to install 5dive's browser now sits in a managed block, so sharing strips it.
