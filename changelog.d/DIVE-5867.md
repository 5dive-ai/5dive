## Unreleased — fix(self-update): the fork-plugin stager skips files, not just non-forks (DIVE-5867)

Every nightly self-update printed `WARN: telegram-opencode-SPIKE.md — no server.ts in the ref, skipping`
and then `up to date: telegram-opencode-SPIKE.md`, because the stager listed every name under
`plugins/` that starts with `telegram-`, and upstream keeps a markdown note with that prefix. It now
lists directories only, so the note is ignored. `tests/refresh_plugins_fork_stage_unit.sh` S1c plants
such a file and asserts it is neither staged, warned about nor reported (red on the old stager).
