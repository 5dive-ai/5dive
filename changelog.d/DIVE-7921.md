## Unreleased — feat(offline-update): boxes trust the owner's offline root key (DIVE-7921)

The CLI now carries 5dive's offline root public key (fingerprint
`3600538264440b0f…`), and `packaging/offline/trust/` holds the root-signed certificate
for the release signing key plus revocation list 1, byte for byte from the owner's
key ceremony. A box running this release checks an offline update file's signing key
against that root before it trusts the file, so a stolen or retired signing key can be
revoked without shipping a new CLI.

PR checks and the offline harnesses use a throwaway root that certifies the run's
throwaway signing key, so they take the same chain a shipped box does. The USB install
check now also asserts the box pins the root its 5dive carries.
