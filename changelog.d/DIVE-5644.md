## Unreleased — fix(task): merge-gate crumb files are removed on exit; the keep-alive rule reaches edited projects CLAUDE.md files (DIVE-5644)

The merge-gate's per-process files `.5dive-gate-tok-trace.<pid>` and
`.5dive-anon-outcome.<pid>` were never deleted. One host had 46k of them in /tmp,
the heartbeat adds about 290 a day, and a process that drew a recycled pid could
print another seat's leftover token trace. Both are now removed by the CLI's exit
handler when the process ends. The trace is still readable for the whole run,
including after the `$( )` it was written in.

The rule that shells older than 15 minutes are reaped unless their command contains
`FIVEDIVE_KEEP_ALIVE=1` moved into the managed task-lifecycle block of
projects/CLAUDE.md. That block is synced on every install, so a box whose file was
edited now gets the rule too. Before, only unedited files received it.
