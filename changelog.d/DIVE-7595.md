## Unreleased — fix(chat): `chat devices ls` exits 0 when every device is approved (DIVE-7595)

`sudo 5dive chat devices ls` (and bare `sudo 5dive chat devices`) printed the paired
devices and then exited 1 with "a bug in the CLI" whenever no device was waiting for
approval, so a script or agent checking the exit code saw a failure that did not
happen. It now exits 0, and shows the approve hint only when a device is waiting.
