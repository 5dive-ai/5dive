## Unreleased — feat(bug): an enterprise firm's support code rides the box's bug reports (DIVE-7885)

`sudo 5dive bug --support-code=<code>` saves the firm's support code (shown on
Support in the 5dive app) on the box, once. Every `5dive bug --file` report from
that box then carries it, and 5dive files the report under the firm, ahead of
the normal triage order. A box with no code sends exactly what it sent before.
`--support-code=none` removes it.
