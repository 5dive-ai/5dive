## Unreleased — fix(agent): a Codex employee keeps the owner's standing rules after a restart (DIVE-8833)

A pack tells its employee to write each standing rule («всегда…», «никогда…») into `~/.claude/owner-rules.md`, which Claude Code loads every session. Codex never read that file, so on a Codex employee a rule was gone after the next restart.

Now every Codex start copies the file into a marked block of the employee's `~/.codex/AGENTS.md`, just below the pack's own section. The owner's file is only read, never written; text outside the block is untouched; an absent or empty file leaves no block. The block is never exported with a pack and is not carried into `CLAUDE.md` on a switch back to Claude Code, which reads the file itself. Claude Code seats are unchanged.
