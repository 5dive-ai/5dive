## Unreleased — fix(heartbeat): bound the rung-2 sibling hold to the current stuck stretch (DIVE-9183)

The starvation lever (rung 2 of nudge enforcement) held a stuck row forever once its first rung had fired days earlier: the "is the seat busy with other work?" check counted any row the seat had touched since then. It now asks only whether the seat did other work since it was last handed this row, so a seat that keeps going idle on the same row no longer holds it. A nudge count that restarted after the row was unparked now arms rung 2 after the usual number of fresh nudges instead of on top of the old count.
