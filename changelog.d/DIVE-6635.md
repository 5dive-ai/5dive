## Unreleased — fix(agents): every claude agent is told how to reach its team (DIVE-6635)

Every claude agent's own instructions now carry a short team block: `5dive agent
list` shows the team and `5dive agent send` reaches any agent, one with no
Telegram channel too (Claude Code's own ListAgents and SendMessage see only the
session's subagents). The same block says the agent's role holds on any model,
the owner has no terminal so is never handed a command, the owner may hear the
agent's rules, and a "can't" is checked a second way before it is remembered.
Updates add the block to existing agents too, and rename the old model-tiering
heading that a lead read as "orchestrator mode is off".
