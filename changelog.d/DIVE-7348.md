## Unreleased — feat(web-chat): Pi and OpenCode agents answer in the 5dive app chat (DIVE-7348)

A Pi or OpenCode agent can now be chatted with from 5dive.app. Before, every
web-chat check refused both types, so the app could not turn the chat on for
them.

- `pi` and `opencode` join the web-chat types (`type_has_web_chat`), and their
  channel installers take `dashboard`: no token, just the dashboard inbox.
- `bin/5dive-agent-start` runs the dashboard server beside a Pi or OpenCode
  seat (`--runtime=pi|opencode`), as it already did for OpenClaw. The server
  (dashboard plugin 0.5.34) answers each message with one headless `pi -p` or
  `opencode run` turn in the chat's own session, from the seat's work folder,
  with the variables the seat's pane drops dropped here too.
- A seat on `telegram,dashboard` keeps its Telegram bridge. The boot script used
  to start the Pi/OpenCode Telegram relay only when the channels were exactly
  `telegram`; it now looks for telegram anywhere in the list. That matters now:
  on a box linked to the app, a new Pi or OpenCode agent starts on the app chat,
  and connecting Telegram later makes the list `telegram,dashboard`.

Harness: `bash tests/dive7348_pi_opencode_web_chat_unit.sh`, 26 arms.
