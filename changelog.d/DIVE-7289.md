## Unreleased — fix(team): a renamed team still imports by its old name (DIVE-7289)

A registry team is found by its slug, so renaming one (`dropshipping` -> `ecommerce`)
broke every saved command, link and box that still used the old name: `team import
dropshipping` answered `no template 'dropshipping'`. An index entry may now carry
`aliases`, the slugs it used to have. `team import` and `team ps` resolve a name by slug
or alias, and `team ls` lists the team once, under its new slug.

A box that imported the team under an old name keeps that project key, because a new
key would record a second team holding the same agents. A box that has neither gets the
new slug.

`tests/team_registry_unit.sh` T15-T17 cover an old name resolving to the renamed
template, a fresh import keyed by the new slug, and a box keeping the key it already
has; all three fail against the unfixed `src/cmd_compose.sh`.
