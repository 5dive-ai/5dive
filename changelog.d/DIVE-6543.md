## Unreleased — fix(team): a team names its pushers, and a merge lands only the graded commit (DIVE-6543)

A team file had no per-seat push key, so every seat a team brought up got the same push rights, including the reviewer. A team member can now declare `can_push: true|false`. Once any seat in the team declares it, the seats that do not get no push grant and a standard tier; `true` forwards `--can-push` to the seat's create. A team that never uses the key behaves as before. The deploy team names anton and dario as its pushers.

The verifier merge checked that the graded commit was the pull request head and then ran a plain squash merge, so a push landing between the check and the merge went in ungraded. The merge now refuses a head that is not the graded commit and pins it (`--match-head-commit`, `expectedHeadOid`), so a later push makes GitHub refuse the merge instead of landing it.
