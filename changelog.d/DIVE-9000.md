## Unreleased — feat(bug): a self-hosted box hears back on the bug reports it sends

A box with no 5dive account behind it (the curl install) could send `5dive bug --file`, but 5dive had no way to answer. Now the report comes back with a private reply code that only this box keeps. Once a day the box asks 5dive whether there is an answer, and if there is, its lead agent tells the owner: "5dive replied to your bug report <n>: …". It stops asking once the report is fixed, or after 30 days. Nothing about the owner leaves the box.
