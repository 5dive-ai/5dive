## Unreleased — chore(core): `5dive partner hire` moves to the hosted plugin (DIVE-9324)

`5dive partner hire` only works against 5dive's own servers, as the box, so it left the public core for the new `hosted@5dive-plugins` plugin. The command, its flags, its messages and its exit codes are unchanged.

A box 5dive built (it holds `/etc/5dive/provisioning.env` and a box token) gets the plugin in the same install or upgrade that removed the built-in, so a partner client's agent can still hire. A self-hosted box is never touched; there `5dive partner` says it comes with a 5dive-built box and points at `5dive hire`.

The box-token reads other commands share (bug reports, the a2a vouch, the first-job intro, the helper handover, premium-team updates) stay in core, in `src/lib/box_token.sh`.
