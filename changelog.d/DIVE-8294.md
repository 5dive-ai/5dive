## Unreleased — fix(openclaw): give each OpenClaw agent its own gateway port so a second one on the same server answers (DIVE-8294)

Every OpenClaw agent listened on the same local port (18789), so on a server
with two OpenClaw agents the second one's gateway could not start and it never
answered. Each OpenClaw agent now gets its own port when it is created (18789,
18989, 19189, ...), and the agent start writes it into that agent's OpenClaw
settings. Agents made before this keep working: the first keeps 18789, and any
other one moves to a free port on its next start.
