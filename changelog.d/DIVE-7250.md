## Unreleased — feat(telegram-access): groups --answer=owner, the agent answers only its owner in a group (DIVE-7250)

An owner can now put their agent in a shared group without the other members
being able to use it.

- **`5dive agent telegram-access groups <agent> --answer=owner`** joins
  `--answer=name|every`. In every group the agent answers only when its owner
  names it, @mentions it or replies to it. Anyone else's message is dropped on
  the box, so it never reaches the agent, not even as context for a later call.
- It is refused on a box with no owner on record, and on a telegram plugin too
  old to know the setting. `telegram-access` read now lists the answers the
  plugin supports (`answers`), so the Mini App only shows the option where it
  works.
- Switching back to `name` or `every` clears only the owner-only member list
  this setting wrote.
