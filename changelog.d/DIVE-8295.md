## Unreleased — feat(task): a new board numbers its tasks TASK-1, TASK-2 … (DIVE-8295)

- **A board created from this release on numbers its rows TASK-N**, not DIVE-N: 5dive cloud, partner boxes and self-hosted boxes alike. A customer's board no longer carries our internal brand on every row.
- **Every existing board keeps DIVE-N.** Nothing is renamed and no flag or migration runs: the prefix is only chosen when the board is first created, so old links, branch names and commit refs stay valid.
- **The CLI no longer assumes DIVE when it reads an ident out of text.** The heartbeat's stale-nudge check, the supervisor's goal-drift probe, `loop install` and `task add`'s numbered follow-up hint now accept any prefix the board mints. On a TASK board the old DIVE-only patterns found nothing and failed open silently. Help text shows `TASK-N`.

Harness: new `tests/task_prefix_default_unit.sh` (20 arms; a fresh board gives TASK-1 and show/assign/done work on it, a board with DIVE rows stays DIVE, the heartbeat parser on a TASK ident; the pre-fix seed turns 11 red, the pre-fix heartbeat 3). The shared test lib pins `FIVEDIVE_TASK_PREFIX=DIVE` so existing harnesses keep their DIVE fixtures.
