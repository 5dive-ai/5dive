## Unreleased — feat(offline-update): pin the release signing key (DIVE-7580)

Offline office servers can now accept a signed update file from a disk. Until now
`OFFLINE_UPDATE_PUBKEY_PEM` was empty, so every box refused every update file
("this box holds no update key").

`src/lib/offline_update.sh` now pins the public half of the release signing key
(ed25519). The private half lives only in the `OFFLINE_UPDATE_SIGNING_KEY` repo secret,
where the offline-update workflow signs each release file. There is no backup copy by
design: if that secret is lost or leaked, a new key reaches offline boxes only by a
manual reinstall.

`tests/self_update_offline_unit.sh`: the NO KEY case now also clears the compiled-in
key, since with a key compiled in, a missing box key file falls back to it.
