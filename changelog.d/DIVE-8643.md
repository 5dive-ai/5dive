## Unreleased — fix(owner): an owner's typed yes on a browser step now gets them the Approve button instead of leaving the row stuck (DIVE-8643)

When an agent asked to use the browser and the owner answered with a typed Telegram "yes" (or «да»), that answer could not approve the browser step, so the row sat blocked until the 30-minute ask ran out and nothing reached the owner to tap. Now the owner is sent the ask's own Approve/Decline card and the agent is told to wait for that tap. A typed "no" still sends nothing, and no proof rule was loosened.
