## Unreleased — fix(memory): consolidate lists the atoms a live session wrote itself (#1311)

`memory consolidate` hands the distiller the atoms a session already produced, with the
instruction not to restate them. That list matched only `run:<session>`, which only
consolidate writes. An atom the live session saved by hand was missing: Claude Code's own
memory writer stamps `originSessionId: <session>`, and `cat >`, `echo >>`, `sed -i` and
`memory add` stamp nothing. A later pass over the same session then wrote the fact again
under a new slug, usually in English beside a Russian original. All 9 duplicate pairs on
claude-konst's 2026-10-12 lint had this shape.

The lookup now also matches `originSessionId: <session>`, and any atom the transcript's
tool calls name by file or by `memory add --name=`. The prompt says a fact in another
language is the same fact. Replayed on that seat's backup with the live distiller, 4 runs
per side: main wrote the role-card duplicate in 3, this branch in none.

`tests/memory_consolidate_unit.sh` adds 14 arms (red on main) and a mutant that drops the
transcript argument.
