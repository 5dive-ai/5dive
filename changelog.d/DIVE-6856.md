## Unreleased — fix(gate): a secret ask on a partner box names no 5dive, and ✅ Provided no longer closes a gate with no key (DIVE-6856)

On a partner box, a request for a key is now the agent's ask, one plain line and a button: the secure link, or the partner's own app when no link could be made. It carries no task number, no command and no 5dive name, in the first message and in reminders. On every box, a secure-link key request no longer shows a ✅ Provided button (saving the key closes it by itself), and a Provided answer from an older message is refused until the key is really saved, so the agent is never told a missing key is set.
