## Unreleased — fix(agent): `agent info` on a drifted seat and `agent cos` without root answer instead of crashing (DIVE-7861)

`5dive agent info <seat>` exited 1 with the generic "exited 1 without reporting a reason"
banner on every seat whose account had drifted, which is the one case its DIVE-7747 drift
check exists to show. The check's "drift" and "unreadable" answers are non-zero return codes,
and `set -e` ended the run before they were read. Both are now read: a drifted seat exits 0
with `authProfileOnDisk.state=drift` naming the registry, env and link accounts (and the
DRIFT line and heal hint in text); an unreadable env file is `unmeasured`.

`5dive agent cos <sub>` run by a seat that cannot write `/opt/5dive` died on a raw
`Permission denied` and the same banner. It now refuses first, with the same root refusal
and exit code (10) as `5dive doctor`, and a seat whose sudo grant covers the verb is re-run
under it. The two runner files are also rewritten only when their contents changed, and are
renamed into place so a concurrent call never reads a half-written file.

`tests/info_drift_cos_root_unit.sh` drives the built bundle against a temp state dir; on a
bundle built from the previous main 16 of its 19 checks go red.
