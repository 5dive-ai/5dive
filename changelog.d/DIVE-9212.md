## Unreleased — fix(secret): a refused paste on a secure link shows the form again (DIVE-9212)

An owner pasted a key into a secure link, the page refused it, and then showed only the
rule with no box to paste into. On a phone that was a dead end: a refresh re-sent the same
refused value, and the only way back was to find the chat message and reopen the link.

- **Every "Not saved" page on a live link now shows the same form again**, with the reason
  above it: a refused value (the connector's rule), an empty box, or a form from another page.
  The single box, the multi-key boxes, the login pair and the card form all come back empty;
  the refused value is never filled in.
