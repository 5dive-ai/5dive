## Unreleased — fix(qwen): new Qwen seats default to qwen4-max-preview, and the newer Token Plan host gets its context window (DIVE-8325)

A **new** Claude seat on Qwen (`agent create --provider=qwen`, `agent auth set claude --provider=qwen`,
or `5dive init` → custom → Qwen) now runs `qwen4-max-preview` on its opus and sonnet tiers, not
`qwen3.8-max`. Haiku stays on `qwen3.6-flash`: there is no qwen4 flash model yet.

**Existing Qwen seats keep the model they have.** The default is read only when a seat is created or
its auth is set again. To move one: `5dive agent auth set claude --provider=qwen` on that seat, or
pass `--model=` yourself.

A box owner asked for this default. `qwen4-max-preview` was smoked live on a Token Plan key on
2026-11-12 (200, served as `qwen4.0-max-preview`). It is a preview id, so the vendor may rename it.

Also:

- **The newer Token Plan host gets its context window.** A seat pointed at
  `https://token-plan.maas.qwencloudapi.com/apps/anthropic` (what the vendor console now shows) got no
  window from DIVE-8308 and compacted at Claude Code's 200k guess. It now gets 983,616 like the
  shipped host. The shipped default host is unchanged: the same key works on both.
- **The init picker names the key it needs:** a Token Plan subscription key (`sk-sp-...`). A
  pay-as-you-go key gets only a bare `InvalidApiKey` from a Token Plan host.
