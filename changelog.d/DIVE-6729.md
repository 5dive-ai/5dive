## Unreleased — feat(agent): "Answers to" lists every name an agent answers to in its Telegram groups, its bot name too, and the owner can remove any (DIVE-6729)

`5dive agent telegram-access groups <name>` now returns `names` as EVERY name that calls the agent in a group. Until the owner saves the list, the word the telegram plugin takes from the bot's Telegram name (getMe `first_name`, the first run of letters) comes first, then the stored extras. `--names=` writes the whole list and sets `groupsCallNamesComplete` in access.json, so the plugin (0.5.107+) stops adding that word on its own and the owner can remove it. An empty `--names=` is allowed: then only an @mention or a reply wakes the agent. Every reply carries `namesComplete`: true means `names` is the whole list and `--names=` replaces it; false only when the bot's name could not be read and the list was never saved, so a caller keeps the old "Also answers to" field. The card-name seed (`seed-names`) still adds to the list without marking it whole. This is the box half of the app field "Answers to".
