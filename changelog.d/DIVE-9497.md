## Unreleased — fix(agent): moving a Russian-language agent to ChatGPT no longer fails halfway (DIVE-9497)

Moving an agent from Claude to a ChatGPT account (`agent set-account <name> <account> --switch-harness`, the cabinet's "move to ChatGPT") could stop the agent and then fail with no reason when its memory or instructions were in Russian or another non-Latin script and long enough to be trimmed for Codex: the trim cut a letter in half, or a long instructions file broke the pipe. Both trims now cut cleanly at a whole line. The move also waits 30 seconds, not 90, for the agent's handoff note, so an agent that cannot answer (out of allowance, dead key — the reason people move it) no longer runs out the cabinet's time before anything switches. `agent switch --handoff-wait=` is unchanged; `FIVEDIVE_SWITCH_MOVE_HANDOFF_WAIT` sets the move's wait.
