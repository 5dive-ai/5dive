## Unreleased — fix(install): the install and `5dive init` end with one link to the phone app (DIVE-6815)

The phone-app hint printed after the install and at the end of `5dive init` was three steps: paste two connector commands, read a code off your server, type it at 5dive.app. It is now one line, marked optional, and one link, `https://5dive.app/self-host`, where you sign in and copy the single command that links your server. It stays silent on a box 5dive built, on a box whose connector is already linked, and with `FIVEDIVE_APP_HINT=0`. Both READMEs drop the retired connector commands for the same link.
