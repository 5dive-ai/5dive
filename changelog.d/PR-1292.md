## Unreleased — fix(avatar): the portrait backfill no longer stops at the first agent (#1292)

`5dive agent avatar backfill`, which `5dive update` runs once per box, died on its first agent and set no portraits. Run as the agent from root's working directory, the persona search exited non-zero. Run from `/`, the next agent's missing OpenAgent page (a 404) ended it the same way. It now runs from `/`, keeps whatever the search found, and treats a 404 as "no portrait for this agent" before moving on.
