## Unreleased — fix(heartbeat): `--fresh` wakes a Codex pane seat again (DIVE-7870)

A Codex seat on its own screen (no Telegram or dashboard) with `heartbeat --fresh`
never got a task: every tick failed at "/clear injection", because the heartbeat
waited for the seat to start working after `/clear`, and Codex stays idle after a
reset by design. A `/clear` (also `/goal clear`, `/compact`) now counts as sent once
it has left the input box, and the task follows. If it is still sitting in the input
box after five tries, the wake still fails loudly and the leftover line is erased so
it cannot fire later.
