## Unreleased — chore(core): the pre-sale handover moves to the hosted plugin (DIVE-9329)

What the owner told 5dive before buying (their business, one or two suggested hires) still goes to their first hire once, but the code left the public core for `hosted@5dive-plugins` (0.4.0, `5dive handover status`): it only talks to 5dive's own servers as the box. The heartbeat runs it only on a 5dive-built box that has not handed over yet; every other box pays one file check.

`5dive helper` is gone. New boxes have had no helper seat since 0.141; the one welcome a seat built by 0.138-0.140 still owed is retired, and such a box gives the handover to its first hire instead. The seat itself is left as it is.
