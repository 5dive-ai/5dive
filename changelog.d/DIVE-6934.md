## Unreleased — refactor(buzz): buzz leaves the core CLI for its plugin (DIVE-6934)

- **The buzz commands moved to the buzz plugin.** `5dive buzz …` and `5dive agent buzz …` now come
  with `5dive plugin install buzz` (buzz 0.2.0 in 5dive-ai/5dive-plugins). A box without it answers
  every buzz command with one line: `Buzz is a plugin now: 5dive plugin install buzz`.
- **Installs and upgrades no longer download the buzz binaries.** The plugin stages `buzz` and
  `buzz-pair` itself, pinned to the same release and checksum. A box that already has them keeps them.
- **What core keeps:** `buzz` as a channel name (`agent create --channels=buzz`, managed settings),
  the seat permission the channel's bridge uses, and a hand-over of `agent buzz <sub>` to the
  official plugin only.
- **Dropped:** a seat's `agent send` is no longer echoed into its buzz room.
