## Unreleased — feat(self-update): online updates are checked against 5dive's signing key before they run (DIVE-7816)

`5dive self-update` now downloads a signed release manifest, checks it against a
root key built into the installed CLI, and installs the installer and program
from the signed commit only when both match their signed hashes. A revoked or
expired signing key is refused. This release is warn-only: a failed check is
logged and shown by `5dive doctor`, and the update proceeds. See
docs/signed-updates.md.
