## Unreleased — fix(heartbeat): a self-installed box gets the cron that starts board work (DIVE-6853)

A self-installed box never got the cron that runs `5dive heartbeat tick`, so a new team's board rows never started on their own, even though `agent create` said the tick would hand them work. The installer now adds it (`/etc/cron.d/5dive-heartbeat`, every 5 minutes) unless the box already runs one, and `agent create` adds it too. If there is still no driver, create says so plainly. New: `sudo 5dive heartbeat install` and `sudo 5dive heartbeat uninstall`; uninstalling the CLI removes the cron.
