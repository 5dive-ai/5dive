## Unreleased — feat(auth): agent auth submit --code=- reads the callback code from stdin (DIVE-8292)

`5dive agent auth submit <session> --code=-` now reads the sign-in callback code from stdin, so a caller that holds the code (the self-host reporter relaying a code pasted in the app) never puts it in argv, a process listing or a log. Empty stdin fails with "no callback code on stdin". The plain `--code=<code>` form is unchanged.
