## Unreleased — fix(supervisor): the ID-verification alert fires only when a seat is stuck on the challenge (DIVE-7325)

The supervisor paged the owner when an agent merely wrote about an ID check. One agent's own reply quoted the test phrase, and the alert told the owner to move the account that same day.

Two checks now stand in front of the alert. Lines that are the agent's own writing (its replies, its tool output, and the messages typed to it) are skipped, so only a real screen or banner counts; the harness's own `API Error` lines are still read. And a hit trips only when the seat's transcript has not moved for 10 minutes (`SUPERVISOR_VERIFY_STALL_MIN`), because a real challenge blocks the session. A seat whose transcript age cannot be read still trips, as before.
