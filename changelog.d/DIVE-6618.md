## Unreleased — fix(plugin): self-update upgrades official box plugins and reports the rest (DIVE-6618)

A self-installed server's nightly `5dive self-update` refreshed the CLI and the agents' plugins but never the box-wide plugins under `/var/lib/5dive/plugins`, so a fix shipped in a plugin (voice's edge-tts floor) never arrived. `install.sh --upgrade` now runs `5dive plugin auto-upgrade`: each official plugin is refreshed from its marketplace and moved to the newest version there, never downwards and never while disabled. Community plugins are reported (`<plugin> at 1.0.0, the marketplace offers 1.1.0`) and left for their owner. When a new version changes what its host setup installs, that setup runs again if the owner ran it before, and otherwise the update says it is owed. A plugin that cannot move gets its own reason and never fails the CLI upgrade. `5dive update --check` now lists box plugins that are behind (`hostPluginsBehind` in `--json`). Agent start no longer prints nvm's `NPM_CONFIG_PREFIX` warning.
