## Unreleased — fix(doctor): warn when a seat is parked in the registry but its unit is still running (DIVE-6382)

`5dive doctor --category=registry` now prints a `registry/parked-running` WARN for each seat whose
registry `desiredState` is `stopped` while its unit is active. The update restart for such a seat is
held until someone reconciles it, so before this it could miss every release for weeks while `agent
list` said ready and doctor said nothing. The warning names the seat, how long its update restart has
been owed (or "no restart owed"), and both ways out: `5dive agent stop <seat>` if the park is real,
`5dive agent start <seat>` if it is stale. A seat that is parked and actually stopped is not reported.
