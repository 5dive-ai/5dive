## Unreleased — feat(marketplace): connect a Vultr or DigitalOcean server from the browser, no terminal (DIVE-7731)

- **Connect a marketplace server without a terminal.** A server made from the 5dive image on Vultr or DigitalOcean now opens a one-time page at its own address. Type the root password your hoster shows, sign in to 5dive, tap Connect, and the server links itself. The password is checked on the server and never sent anywhere. The page closes for good once the server is linked, after 10 wrong passwords, or 24 hours after first boot. A DigitalOcean Droplet made with an SSH key gets its password from Access › Reset root password.
