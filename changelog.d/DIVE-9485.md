## Unreleased — fix(cli): `--help` works on every command's subcommands (DIVE-9485)

`5dive secret link --help` (and `-h`) and `5dive market search --help` (and `-h`) used to fail with "unknown flag" or "bad task ref", or ran a market search for "-h". They now print the command's usage and exit 0. This is fixed for every command at once, not one at a time: asking `--help` after any subcommand prints that command's usage instead of running the subcommand (before, `tool ls --help` listed the tools and `wall <seat> --help` opened a terminal). `5dive activity`, `cost`, `objective`, `project` and `trace --help` now print their usage even where the command itself would refuse. A new test walks every command in the CLI so a new one cannot ship without `--help`.
