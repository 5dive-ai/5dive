## Unreleased — fix(secret): a refused paste names the rule it broke and tells the agent (DIVE-6727)

A paste the secret link refused used to show only "Not saved. The server refused that value."
The owner retried blind against a rule they could not see. The page now names the rule for
that kind of key: one line with no spaces or quotes for a tools key, the allowed character set
for a project key, and a pointer to a named connector for multi-line values. The agent that
filed the gate is told a paste was refused and why (at most once per link per 10 minutes),
never the value itself.
