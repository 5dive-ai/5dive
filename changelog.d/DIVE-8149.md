## Unreleased — fix(agent share): an agent with our default skills can be shared again (DIVE-8149)

`5dive agent share` (and the app's Share button) refused every agent that carries our default skills: the `5dive-cli` skill's command reference names task ids and `sudo` on purpose, and the owner could not reword our file. A skill that comes from our public skills repo and is byte-for-byte what its lock file pinned is now left out of the privacy check; it still travels with the share. One edited line and the skill is checked again, and the refusal names that line. A refusal now opens with one plain sentence before the list of lines.
