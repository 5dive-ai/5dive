## Unreleased — fix(import): an agent imported on a server with no AI yet thinks once you add one, in either order (DIVE-7848)

On a fresh self-hosted server, `sudo 5dive agent import marcus --as=marcus` used to
finish with an agent that could not think, and adding the AI afterwards did not fix it:
the agent sat on an empty account of its own, and only a per-agent sign-in line woke it.

Now, at a terminal, the import asks first and runs the same AI step `5dive init` runs
(sign in, or paste a key), so the agent answers when the command ends. Off a terminal,
or if you pick "Later", the agent waits for the server's first AI: `5dive init`,
`account login`, `account set` or `agent auth login|set` moves it onto that AI and
starts it, with no per-agent command to know. It only moves onto an AI of its own kind
(a Codex agent never lands on a Claude sign-in).
