## Unreleased — feat(onboarder): one locked-down chat agent per prospect firm

`sudo 5dive onboarder create <slug> < brief.json` makes agent `onb-<slug>` for one firm: a sandboxed Claude seat whose only channel is the web chat, with no skills, team bot, heartbeat or memory. Its rules, the box's fact sheet (`/etc/5dive/onboarder/fact-sheet.md`) and the firm's brief go in a root-owned CLAUDE.md. The brief carries public facts only: a contact's name and role at most, and an email address, phone number or any unknown field is refused. The seat is created stopped. `onboarder wake <slug>` starts it for a message, and a minute timer (`onboarder tick`) starts a seat with a queued message and stops one idle for 2 hours. `onboarder rm <slug>` removes it, and `onboarder ls --json` lists slug, firm, domains, band, setup and running.

An onboarder seat starts with no tools: no built-ins (`--tools ""`, each one also denied by name), no slash commands, and `dontAsk` with the chat's reply tool as the only allowed tool. Its chat channel sends text only (dashboard plugin 0.5.43). Either the `AGENT_ONBOARDER=1` stamp or the root marker in `/etc/5dive/onboarders/` turns the mode on, and neither can turn it off.
