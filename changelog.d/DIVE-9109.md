## Unreleased — feat(team): premium team files, signed by 5dive and stamped with the buyer (DIVE-9109)

A premium team now comes as one `.gz` file made for one buyer. `5dive team import <file>` checks that 5dive signed it with a team key the offline root trusts (expiry and revocation included), refuses a file that was changed, says whose copy it is, and installs the team. The buyer's name and account are also stamped inside the team itself, so a passed-on copy can be traced even with the signature removed. Free team files import exactly as before.
