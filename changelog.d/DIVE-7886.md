## Unreleased — feat(panel): an office server with no internet saves a Support file from its control panel (DIVE-7886)

Settings in the office control panel gets a "Need help?" card: describe the
problem, tap Save support file, and the browser downloads the report
`5dive bug --file` would have sent, byte for byte. Carry it to any computer
with internet and attach it in Support in the 5dive app. The server sends
nothing. From a terminal the same file is `5dive bug --what="…" --save=<path>`.
