## Unreleased — fix(agent): agent list shows real agent state on Ubuntu 22.04 (DIVE-7331)

On Ubuntu 22.04 (systemd 249), `5dive agent list` showed every agent as STATE unknown and ENABLED unknown, because systemd 249 does not accept `systemctl show --timestamp=unix` and fails the whole call. Now it falls back to `--timestamp=utc` when that happens. The seat's start time, which decides whether an old login refusal still counts, falls back the same way. Ubuntu 24.04 behaves as before.
